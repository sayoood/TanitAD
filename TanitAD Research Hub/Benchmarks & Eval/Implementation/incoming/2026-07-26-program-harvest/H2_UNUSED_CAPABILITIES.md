Every row below was re-verified with a precise import-pattern grep (or a real `pytest` run) before being
admitted — this is exactly the class of error CLAUDE.md's own rule 2 warns about ("absence found at
ONE location is not absence"), and it bit my own first pass here.

**Evidence discipline applied per row:** every claim carries an evidence class
(`MEASURED (ours + artifact/command)` / `PUBLISHED` / `INHERITED (a doc, not re-verified by the final
compiler)` / `ESTIMATED` / `HYPOTHESIS`) and a tier (`PROVISIONAL` = one path unreproduced / `CONFIRMED`
= independently reproduced, either by two of the four sub-sweeps or by the compiling agent re-running
the sibling agent's exact claim / `DECISION-GRADE`). Sub-sweep findings not independently re-run by the
compiling agent are marked `INHERITED` even where the sub-sweep itself ran a real command — that
agent's MEASURED becomes this table's INHERITED-from-a-agent-report until a second path confirms it,
per the same discipline CLAUDE.md applies to inter-agent claims generally.

**One cross-agent disagreement surfaced and is stated, not smoothed over:** CLAUDE.md's own text
("LAL-v2 anticipation: implemented, tested, unmerged 12 days") is confirmed STALE by two independent
paths that name **two different mechanisms**. Sub-sweep B did a targeted `git log -S "def
compute_lal_v2"` and function-level diff, finding the merge landed in `stack/tanitad/eval/metrics.py`
(commit `3784e34`). The concurrent H3 sweep (this directory's `H3_STRANDED_INTEGRATIONS.md`, item D-02)
instead attributes the same CLAUDE.md sentence to `taniteval/taniteval/rollout.py`'s "dense path" (added
2026-07-25). Both are independently MEASURED and both are real, applied fixes — they may be two
genuinely different "anticipation" mechanisms that both happen to be described near the phrase
"LAL-v2", or one sweep misattributed the source. **Not adjudicated here** (H4 territory — unresolved
cross-agent contradiction); flagged so the registry owner picks the right citation rather than either.

**Excluded by design, not oversight:** the ~340 correctly-disposable one-off analysis drivers found by
