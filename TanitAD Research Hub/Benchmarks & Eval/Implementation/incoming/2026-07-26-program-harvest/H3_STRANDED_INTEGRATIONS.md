## Method

Swept `TanitAD Research Hub/*/Implementation/incoming/*/` (136 dirs at sweep time — the brief said
135; `Project Steering/BOOST_PROGRAM.md` §7 itself says 134; all three counts are believable given
new dirs land mid-session — nobody's number is wrong, the corpus is moving), plus `*/Research/`,
`Project Steering/*.md` (root), and `Project Steering/Reviews/`. Grep (case-insensitive, ripgrep) for
the pattern set given in the brief (`escalat`, `needs? an owner`, `one-line fix`, `must/should be
merged`, `not (yet )?(merged|wired|applied|integrated)`, `still (live|owed|open)`, `TODO`, `FIXME`,
`not patched`, `owed`, `unmerged`, `follow-?up (required|owed)`, `blocked on`, `awaiting`, `hand off`,
`NOT DONE`, `pending`) plus `stranded` (the task's own title word). This surfaced 320+ file hits;
low-precision keywords (`TODO`, `pending`, `owed`, `awaiting`) were skimmed for actionable claims and
the high-precision phrases (`escalat`, `needs an owner`, `one-line fix`, `still live`, `unmerged`)
were read in full context. Every candidate below was then **independently re-verified against HEAD**
— `git ls-files`, `git log`, and a direct `Read`/`Grep` of the named file:line or artifact — rather
than trusted from the report that raised it. Where a report's headline and its own escalations section
disagreed with the code, the code (HEAD) wins and is what is reported here.

**Headline: of the 23 distinct claims chased down, 12 are STILL OPEN and 11 are ALREADY DONE** (fixed,
usually same-day, by a later commit the original report's author could not have known about). One item
is UNVERIFIABLE without pod/HF access. The single largest finding: **the module that was written
specifically to "un-strand" the v4 gate co-primary (`taniteval/clhorizon.py`, committed today) still
raises on its first step** — the same bug class it was built to fix, one line, unfixed.

Evidence class is stamped per row: `MEASURED` (I read the code/artifact myself, this session) ·
`INHERITED` (I did not re-derive it, only cross-checked its presence). Tier: `CONFIRMED` (reproduced
via an independent check beyond the original report — usually code-read + a second corroborating
source) · `PROVISIONAL` (single check). Nothing here is `DECISION-GRADE` — this is an inventory, not a
verdict.
