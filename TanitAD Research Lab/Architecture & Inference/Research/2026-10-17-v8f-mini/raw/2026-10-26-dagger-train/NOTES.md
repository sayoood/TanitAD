## 2. Rules and where each is enforced
* **G-DVB** (`bad_dagger`): built p, seed, kin_mode, bank path, bank sha256 (re-hashed from disk) == declared; `swap.problems()` (a seed or bank at p = 0 is "declared and does nothing"; p > 0 with no bank; p outside [0, 1] or NaN; non-yaw); `--ego-perturb-p > 0` together with `--dagger-p > 0` refused; the bank's schema / rollout / constants sha256 / `cfg` (hist, hmax, max_age_t/s, window_start, kin_mode) / history length equal PREREG s1 and THIS model; the K-B2 / K-B3 / COVERAGE records exist, name this bank and passed; K-B2 re-read at the gate against `info["init_ckpt"]`.
* **K-B3 at load** (each its own message, eval read FIRST so an injected eval clip is named as one): eval overlap, bank clip not in the ARM's TRAIN list (after `--exclude` / `--data-frac`), window-list sha256 != `windows_sha256(J["clip"], wins)`; a PARTIAL bank is refused.
* **G-LIVE `dagger_probe`** on the real batch at p = 1, through the same `dag.apply`: keys of the batch unchanged; every key `forward_infer` reads is replaced or kept; no unselected row changes; every selected row is its window's own matched, uncut record (clip, r' = t, reason ok) and its `kin3` IS the bank's; p10f / base / kin3 / p10_t change on every selected row except bit-identical rows (exempted and COUNTED; at least one must be non-identical) and, for `base`, rows at rest in both (counted); every kept key is the SAME object; `lab_s` differs in `rc` only and `rc` equals `DG.rc_frame_change` to 1e-5 (recomputed in the probe); `live_check` on the swapped batch; loss AND gradient move; replacing `p10f` alone moves the loss. **Zero controls, each EXACTLY 0.0:** the same loss twice; p = 0 returns the same object with loss and gradient difference 0; the frozen P10 prior's gradient difference; the world-model auxiliary's.
