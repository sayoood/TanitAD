# STRATROLL10K definitions as coded (reader `strat_roll_read.py`, card PREREG_V8F_PROOF_ADD66)

Tier: first tick of each window T0; ticks 2 and 3 T1-kin (kinematic rollout, logged camera frames, the lead does not react); never driving performance. CPU only, no model, no rollout.

* Steps: grid step j = cache step (0.2 s). Logged pose of step j = native track row 2j (`tracks[clip][0::2, :3]` = x, y, yaw, the same rows the pinned tool stores as `pose`). Frame proof: logged pose at t0 equals `pose_w0` (checked in s2 through `pose`, and in the s3 run).
* Checkpoint to world: `s_ckpt` (x, y, psi at 30, 50, 80 m) in the frame of `s_pose`, rotated and shifted into the world (same arithmetic as `transform_ckpt`, `v8f_mini.py` line 315, numpy float64). Heading = wrap(psi + yaw of `s_pose`).
* Anchor: among logged steps within 25 of (j - age_s), the one whose logged xy (rounded to float32, because `s_pose` is float32) is nearest to the xy of `s_pose`; ties within 1e-6 m go to the step nearest j - age_s. Distance in metres is kept (reported without a bar at ticks 2 and 3).
* Label rule (mirrors `v8f_mini_data.py` lines 1213 to 1223, the synthetic-drive builder): positions after the anchor (steps a+1 on), arc 0 at step a+1, cumulative chord arc; for A in 30, 50, 80 the first step whose arc reaches A (`searchsorted`); label = logged xy and logged yaw of that step; valid only if the final arc reaches A. Non-finite rows end the track.
* `pos` (m) = |checkpoint xy - label xy|. `head` (deg) = |wrap(checkpoint heading - label yaw)|, both world. Valid where the label is valid.
* `lat` (m) = distance of the checkpoint xy to the polyline of logged positions from the anchor on (segment projection); valid if the nearest point is not the last logged point.
* `along` (m) = arc along that polyline from step a+1 (the label's arc 0; chosen so that a label point reads its own arc, the card says "from the anchor") to the foot of the checkpoint, minus A. Signed. Beside it `abs_along` = |along|; the verdict rule is applied to the difference of signed `along` and of `abs_along` alike (lower is better is only meaningful for `abs_along`).
* Windows: 2,399 per run, in `win` order; episode of a window from the dump files of `I10R0_s0` keyed by (clip_index, ws) = (`ci`, `t0`); all runs assert the same (ci, t0) windows.
* REF1 of window w = mean of the first-tick cell of windows w+1, w+2; REF2 = mean for windows w+4, w+5; the neighbour must be in the same episode and start 4 steps per index later; a window enters a ROLL read only if its cell and both reference cells are valid. ROLL1 = tick-2 `pos` minus REF1; ROLL2 = tick-3 `pos` minus REF2, per arc (ticks are 0, 1, 2 in the files; "second tick" = tick 1, "third tick" = tick 2). Share of the first-tick level = pooled mean difference over the mean first-tick `pos` of the same windows.
* Pairs (difference A minus B on windows valid in both runs, per seed): READOUT `R0G0X-R0` (K), `R0C10-R0` (G1), beside `R0G0-R0`, `R0Bk10-R0`; RULE `RLc-R0` (form LABEL), `RQ50-R0` (form READER), beside `RLcF5-RLc`, `RQ50F5-RQ50`; CANDIDATE (only with `--with-cand`, admitted when `READ_CAND10K.json` has controls_all_pass true and all four tick files exist) `RLcKF5-RLc`, `RQ50KF5-RQ50`, beside `RLcK-RLc`, `RQ50K-RQ50`, `RLcKF5-RLcK`, `RQ50KF5-RQ50K`. Run names on disk carry the prefix I10. Named read at the third tick; the second tick is reported beside.
* Estimator: paired episode-cluster bootstrap, B 2,000, `numpy.random.default_rng(0)` per call; episodes with at least one valid window are drawn with replacement; a drawn episode brings the windows of both model seeds; statistic = mean over all drawn windows; interval = 2.5 and 97.5 percentiles; per-seed means beside. Lower is better.
* Verdict per cell: BETTER if both seed means < 0 and the pooled interval is below 0; WORSE the mirror; else NOT-SEPARATED. Family rule over the three named cells (`pos` at 30, 50, 80 m): all BETTER, all WORSE, all NOT-SEPARATED, else MIXED.
* ROLL name: DEGRADES if ROLL2 of `R0` reads WORSE at two or three arcs; HOLDS if neither ROLL1 nor ROLL2 reads WORSE at any arc; else MIXED. Only if s7 passes.
* Names exactly as card section 5: `STRATROLL10K-K-STRATEGIC-...-PINNED`, `-CAUSAL-STRATEGIC-...`, `-<form>-RULE-STRATEGIC-...`, `-<form>-CANDIDATE-STRATEGIC-...-CONVENTION`, forms LABEL (`RLc`) and READER (`RQ50`).
* Controls: s1 (own transform vs `s_ckpt_w0`, 1e-3 m and rad, every row of every file), s2 (first-tick anchor = t0, distance <= 1e-6 m, every file; also executed pose at t0 vs logged), s3 (first-tick label of the card rule vs `J["rc"]`, `J["rc_ok"]` of `hierrep/pins/join_eval141.npz`, ego frame of the window origin, 1e-3 and equal validity), s4 (synthetic, planted fault: every arc replaced by the next), s5, s6, s7 (R0 first tick, windows w and w+2 minus w+1, per arc), s8 (self pair [0,0], swapped pair), s9 (sha256 of every tick file).
* Stage order of the default mode: s4, s1, s2, s3, s6, s9; if any fails the run stops before any cell is computed (JSON carries the controls only). Then cells, s5, s7, s8; names only if s1 to s6, s8, s9 pass (s3 may be NOT COMPUTABLE per the card); s7 gates ROLL only.
* Diagnostic s3b (not a card control): the programme's smoothed route label (`build_v9_labels.py` `smooth_path`, `rc_point`, sigma 8 m, native track as the 10 Hz track) against `J["rc"]`. Sagitta validity is not reproduced.

## Amendment 1 of the card (takes precedence over the lines above where they differ)

* Label: no rule is applied by the reader. The label of a tick row is `rc` / `rc_ok` of the evaluation join at the anchor step (`J["off"][clip] + a`, inside `J["n"][clip]` rows), given in the frame of the logged pose at the anchor step and put into the world frame with that pose (`label_join`). `label_card` (the synthetic-drive rule) is used by the synthetic checks of s4 and by the on-record control only.
* `along` = arc along the logged polyline of the foot of the checkpoint minus that of the foot of the label point (a checkpoint on its label reads 0); valid if both feet and the label are valid.
* s3 = first-tick `pos` / `head` of the reader against `checkpoint_errors` of the other session (`taniteval/v8f_consistency.py`, imported from the overlay tree) on the raw `s_ckpt` and `J["rc"]`, `J["rc_ok"]` of step t0: at most 1e-3 m and 1e-2 deg, same rows invalid; must pass (not computable counts as a fail). The control as first frozen is kept in the result as `s3_as_first_frozen` (failed).
* s4 has four more checks for the label path and a second planted fault (the heading of the wrong sign).
