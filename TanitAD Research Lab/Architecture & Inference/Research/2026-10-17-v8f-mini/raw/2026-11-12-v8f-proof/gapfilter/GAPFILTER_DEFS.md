## Inputs and layout

* **D1 Row layout of the lead files.** `<ARM>_{eval,train}_lead.npz` hold `presence_logit`, `gap_m`, `closing_ms`, `has_history` per row of the state file of the same split, in state-file order (N1 reader `run`, lines 744 to 790: `load_states`, `ze = np.load(f["eval_lead"])`, `pod_e`). Units are final (gap in m, closing in m/s; N1 `head_out_units`, lines 96 to 97). Rows without a 5-frame history (t below 4) are NaN. The row layout (clips, clip_idx, t) is read from the state file `<ARM>_{eval,train}.npz` keys `clips`, `clip_idx`, `t` only (lazy, no state tensor loaded). Measured on LS_s0: 141 eval clips, 14,237 rows, rows sorted by clip with t = 0, 1, 2, ... contiguous in every clip; train: 1,200 clips, 121,166 rows, contiguous, equal to `train_pack.npz` (checked per arm in f6). The code verifies contiguity and falls back to a key lookup otherwise.
* **D2 Frame step dt.** dt = `O.DT` = 0.2 s (`objslot_s0.py:30`), the step of the bank steps `bg` that index the state rows; window frame f of a window with S0 step g0 is state row t = g0 - 4 + f (N1 reader `assemble_windows`, line 142; the eval pack `G15` is built with the same key, `build_eval_pack` lines 150 to 160). The scoring row of a window is the row with t = g0 (the S0 row), which is key (episode, g0) of the state file.
* **D3 Rows before S0.** The causal input of a window is the prefix of its episode: rows t = 0 .. g0 of the dense per-clip series (gap, presence logit, closing output). A row that does not exist (before the clip start) or whose output is NaN is missing, like a row with presence probability below 0.5. E1 at K uses the K row slots t = g0-K+1 .. g0 (slots before the clip start are missing); E2 runs over the whole prefix from the clip start (restart at the start of a clip is the initial state). Per clip the estimate at every row is computed once; because both estimators are causal this equals the prefix computation, and control f3 and the tests check it.
* **D4 Missing S0 row.** If the S0 row itself has presence below 0.5, the estimate at S0 is still read from the earlier present rows (E1: slope over the present rows of the K slots; E2: the rate of the filter, which predicts through missing rows) provided the present-row rules of the card hold. The estimate is missing only by the card rules.
* **D5 Label closing speed and windows.** The label at S0 and the 413 / 429 windows are the ones of the N1 reader (`window_ctx` line 204: `H.label_c`, `O.scored_mask`, `valid = sc & hok`, 48 episodes, `RP.boot_counts(n10, 2000, 0)` shared by every paired difference). Control f1 is the N1 reader's `control_k1`.
* **D6 Train probe clips: "closing rows".** The rows of the 1,200 train probe clips that carry a closing label: `H.build_fit_sets(names, t, gap, v)["c_ok"]` on `train_pack.npz` (the labels of `leadhead_b`, same as `train_read`, N1 reader line 349), the label being the least-squares slope of the label gap over the trailing run of at most 5 frames, as for the windows. Selection, calibration and E3 use these rows only. Folds: `RP.make_folds(clip names)`, five folds grouped by clip.
* **D7 Gap labels for f2, f7, f8.** The label gap of an evaluation row is the bank `lead_gap` at (episode, t) of `res/cache/frames.npz` (`O.BANKP`), the same file `O.load_label_frames` reads for `G15` (`objslot_s0.py:307`); NaN where the bank has no row or no lead. The dense label series is built for every evaluation clip; a label gap is "present" when finite. f2 and f8 run the same function `estimate_series` as the head path, with the label series in place of the head series (presence = finite).

## Estimators and the selection

* **D8 E1.** Least-squares slope (`O.ls_slope` of the reader, time = slot index x 0.2 s) over the present rows of the K slots; at least 3 present rows else missing. Slots are consecutive row steps, not the last K present rows.
* **D9 E2.** State (gap, rate), dense timeline, one step per row. Prediction gap += rate * dt on every row once initialised. Present row: first present row after a restart sets gap = measurement, rate = 0 and counts as present row 1; later present rows use residual r = measurement - predicted gap, gap += alpha * r, rate += (beta / dt) * r. Missing row: missing run + 1; when the run exceeds 5 the filter restarts (state cleared; the next present row initialises). The estimate of a row is the rate after the update of that row if at least 3 present rows since the restart, else missing (also on a missing row while the filter is alive).
* **D10 Calibration and fallback.** closing = a * estimate + b by least squares on the rows with a finite estimate and a finite label. F = calibrated estimate where the estimate is finite, else the uncalibrated closing-speed output of the head at that row (count printed). The same F (fallback included) is what selection scores.
* **D11 Selection (train probe clips only).** Candidates: E1 at five K, E2 at sixteen (alpha, beta). For each candidate: five clip-grouped folds; calibration fitted on four folds, F applied to the fifth; score = mean over the five folds of the fold MSE (rows with a closing label, F finite). The best K and the best (alpha, beta) are the lowest scores (first on ties); the chosen estimator F is the lower of the two best scores; then (a, b) refitted on all closing rows of the train probe clips. The selection function receives train rows only; the evaluation labels are never an argument (f5 runs the whole arm pipeline once with the real and once with noise evaluation labels and compares the selection).
* **D12 E3 (names nothing).** Linear blend (with intercept) of the E1 estimate (chosen K), the E2 estimate (chosen alpha, beta) and the head closing output, least squares on the train closing rows where all three are finite; applied where all three are finite, else the head closing output.
* **D13 Cross-fitted variant (names nothing).** The evaluation bank = all rows of the 141 evaluation clips with a closing label (`build_fit_sets` on the bank gap, speed column zero, labels only). Five episode folds (`RP.make_folds`); for each held-out fold the whole selection (D11) is run on the other folds' rows and applied to the scored valid windows of the held-out fold; pooled R2 with the 48-episode bootstrap.

## Reads

* **D14 M1F, paired difference, DELTA-F.** M1F = R2 of F against `c_lab` on `valid` (413), `fid_one` and the paired difference with the head closing output at S0 of the same arm by the construction of the N1 reader (`eval_read`, lines 324 to 327: `ep_stats_r2`, `boot_r2`, `diff_row`, shared draw). The head output at S0 is the pod output of the S0 row (k2 of the N1 reader ties it to the reader's own forward within 1e-4). DELTA-F = `n1_inputs` and `delta_n1_row` of the N1 reader (lines 291 to 309) with the closing column replaced by F at S0 (R3c) and by 0 (R3n), head gap at S0, logged ego speeds, 429 scored windows. DELTA of the head's own closing output is recomputed through the same call and compared with the N1 result file.
* **D15 Floor.** 0.089 as written in the card; the measured |M1(LSD_s0) - M1(LSD_s1)| = 0.0893 of the N1 result is printed beside.
* **D16 Rule for "mean is larger than the floor".** The mean of the two seeds' point differences (M1F - M1) of the arm type must exceed 0.089, the same reading as the gradient names of the card ADD24.
* **D17 Permuted controls.** f4: the whole per-row sequences (gap, presence logit, closing output of the prefix up to S0) of the scored windows are permuted among the 429 scored windows with rng 0 (four more permutations printed, seeds 1 to 4); the frozen F is applied to the donor prefix; M1F on the 413 valid windows at seed 0 must be at most +0.02. The permuted control of DELTA-F permutes the value of F at S0 among the 429 scored windows (gap and ego term in place), seed 0 gates, seeds 1 to 4 printed, bar +0.02 (the pattern of note N1).
* **D18 f3.** For every scored window and every candidate (and the chosen F), the whole-clip estimate at S0 is computed on the original and on a copy whose rows after S0 are replaced by random values (gap, presence logit, closing); the maximum absolute difference (and the NaN pattern) must be exactly 0.
* **D19 f7.** Over all evaluation rows with a finite head gap and a finite label gap: RMSE of (head gap - label gap); RMSE of the change of that error between consecutive rows of a clip (both rows valid); lag-1 autocorrelation (Pearson) of the error over consecutive pairs. Intervals: bootstrap over the 141 evaluation episodes (rng 0, B 2,000). Beside, the same on rows with head presence probability at least 0.5 (info).
* **D20 f8.** The dense label gap plus white noise (sigma 0.25, 0.5, 1, 2, 4 m; and 0 as reference) through E1 at K = 5, 10, 15 (rows present where the label is finite); closing R2 on the 413 valid windows; 20 noise draws (rng seeds 0 to 19): mean and range over the draws are printed, with n = 413.
* **D21 x1 (alignment, added by the reader).** M1 of every arm from the pod rows at S0 must equal M1 of the N1 result file (tolerance 5e-4) and DELTA of the head's own closing the same; a mismatch is a failed alignment control and blocks names like f1 to f6.
* **D22 Names.** `FILTER-READS-CLOSING` and `FILTER-SLOT-IMAGINES` by the rules of card section 5 per arm type, both seeds present and read; blocked when any of f1 to f6 or x1 fails for any arm (the all-arms rule of the N1 reader) or when an arm is missing. `FILTER-FLAT` / `FILTER-SLOT-FLAT` otherwise.

## Limits

Two seeds per arm type; an interval answers another draw of episodes, not another training run. One corpus. The head read float16 states. A rate from a longer baseline lags a changing closing speed; the label is the closing speed at S0.

## Addendum, written after the first real-data run (the card run is unchanged by it)

* **A1 Finding on f2.** The first run on real data (arm LS_s0 smoke, then all six arms) gave f2 = FAIL: E1 at K = 5 on the label gap reads R2 +0.367 against the bar 0.8. Cause measured by `tmp/diag_f2.py`: 410 of the 413 windows reproduce the label closing speed exactly (to 1e-9, so sign, units, alignment and frame step are right); 3 windows have a lead change inside the last five frames (a step above 3.0 m in the label gap, the same-lead rule of the label path `O.hist_run`), where the label truncates the run and E1 as written fits across the step (slopes of -34, -13 and +7 m/s against labels of -0.3, +1.3 and +2.4). The card fixes E1 and E2 without a same-lead rule. The card run is therefore reported as written: f2 FAIL, no outcome named.
* **A2 Post-hoc variant (names nothing).** `--variant-jump-m 3.0` adds the same-lead rule of the label path to E1 (trailing run of present rows, a step above 3.0 m to the previous present row ends the run) and E2 (a step above 3.0 m restarts the filter). It is written after the f2 number was seen, it is not the card's estimator, it names nothing in any case, and its numbers are information for a later card. Output in `out_jump/`. Default off (`JUMP = None`).
