# LABELUNSAFE10K read definitions (card PREREG_V8F_PROOF_ADD135, kit `labelunsafe/kit`)

Tier T1-kin/hb0.2 on every number (kinematic rollout on the model's own actions); not driving performance. Tool `read_labelunsafe10k.py controls|names`; tests `test_read_labelunsafe10k.py`; pod driver `podread_labelunsafe10k.sh tests|controls|names`.

## Definitions the card leaves open (fixed here, before any real value)
1. Lowest time gaps (tau_m, tau_l) are taken over the scored steps k = 1..n_s of the engine's lead window. "Unsafe step" and "step with a gap below 2.0 m" use the engine's constants (strict, 2.0 m, 1.0 s).
2. The engine's `window_cells` returns g_m and gap_l per step but not the time gaps; the tool forms tau = gap / max(step speed, 0.5) from the engine's gaps and the engine's own `step_speeds` and `V_FLOOR`. Control u0 requires the tool's unsafe flag to equal the engine's U on every U-defined window.
3. "Scored windows" (M3 beside, u0 denominators) = windows on which U is defined (the logged driver has no unsafe step), pooled over the four model seeds (a grid window counts once per model seed).
4. Windows are the pinned-grid windows of the engine: dump arrays cut to the grid with `restrict_idx` (the way the readers of ADD70 to ADD134 do), labels by `label_windows`. A run with a grid window missing or repeated, or with windows that differ from the first run, makes u4 fail.
5. M1 = no step with g_m < 2.0 m. M2 = lowest tau_m >= 0.9 s (beside: median of the lowest tau_m). M3 = lowest tau_l < 1.2 s (strict; beside: same share over all scored windows). M4 = lowest tau_m < lowest tau_l - 0.2 s (strict).
6. M5: windows are grid windows; unsafe count over the four model seeds of RLc; M5 = share of the windows with count >= 1 that have count >= 3. Its bootstrap resamples the same episodes.
7. Bootstrap: episode units from the engine's `episode_units`; one index matrix `default_rng(135).integers(0, n_episodes, (2000, n_episodes))` shared by every measure; share = sum of episode numerators / sum of denominators; draws with a zero denominator are skipped; 95 % interval = percentiles 2.5 and 97.5. Medians and the counts beside have no interval.
8. Beside, by gap: label gap (gap_l) and model speed (v_m, step speed) at the first unsafe step, bands [0,10), [10,20), [20,40), [40,60] m; n, median gap, median speed per band. Step index of the first unsafe step is 1-based (k), with median, quartiles, range and a count per k.
9. Beside GEc: share of its unsafe windows that are also unsafe windows of RLc at the same model seed, per seed and pooled (a seed with no unsafe window of GEc reads nan).
10. Names: clauses evaluated in the order of section 4 (THRESHOLD, then RULE-FOLLOWS-CLOSER, else MIXED); an interval that is not finite makes its clause false (so MIXED / WINDOWS-DIFFER-BY-SEED). Two routines derive the names and must agree, else the tool refuses.
10b. Families line: LONGITUDINAL read here; LATERAL, TACTICAL, STRATEGIC "not read by this card, n = 0 here" (card section 3).
11. u0: expected rates are those of the card (RLc per seed and pooled, GEc and A90 pooled), pooled = mean of the four per-seed rates, tolerance 1e-4, plus the exact equality of the tool's unsafe flags with the engine's U. The engine files (headway_read_r2.py, read_longroll10k.py, q3_read.py, hierrep_read.py) are imported by path, unchanged; their sha256 are in `inputs.files` of the controls file.
12. u1: second routine in scalar form (projection of the model point on the extended logged path, nearest non-degenerate segment, gaps, speeds, time gaps) for every lead window of all twelve runs; lowest tau_m, lowest tau_l, lowest g_m (tolerance 1e-9) and the first unsafe step (exact).
13. u2: "advanced by 0.35 s of travel at each step" = the point of the extended logged path at arc a_l(k) + 0.35 s x logged step speed v_l(k) (engine `logged_arc`, `step_speeds`, `point_at_arc`). The step speed of the planted track at step 1 includes the offset from the origin (p_0 = (0,0) in the engine), so planted windows turn unsafe early; the check is non-vacuous (at least one window becomes unsafe), every such window counts for M4, and a window unsafe by the gap alone (a step with g_m < 2.0 m and none with tau < 1.0 s) must have a lowest g_m below 2.0 m by the second routine. Identity part: model track = logged track, no unsafe window, M4 has no window.
14. u3: each test output (dev box, pod) ends with a pytest summary `N passed` (N > 0), no failed or error count, no FAILED or ERROR line, names `test_read_labelunsafe10k`, and its path has no component `kit` and is not inside the tool's folder.
15. u4: 141 `ep*.npz` files and `T1_DONE` per run (twelve runs); 642 lead windows per model seed on the grid windows.
