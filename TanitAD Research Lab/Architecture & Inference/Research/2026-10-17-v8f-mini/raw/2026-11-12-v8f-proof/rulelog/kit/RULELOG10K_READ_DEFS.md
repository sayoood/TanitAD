# RULELOG10K read definitions (card PREREG_V8F_PROOF_ADD137, kit `rulelog/kit`)

Tier T1-kin/hb0.2 on every number (kinematic rollout on the model's own actions); not driving performance. Tool `read_rulelog10k.py controls|names`; tests `test_read_rulelog10k.py`; pod driver `podread_rulelog10k.sh tests|controls|names`.

## Definitions the card leaves open (fixed here, before any real value)
1. Steps are counted from the window origin (log column `k` = frame minus t0, k = 0 is the origin). Ticks are the steps 0, 5, 10, 15, 20, 25: the tick log has k = 0, 10, 20 and the later-look log (`rule_log_mid_*`) k = 5, 15, 25; both files are read and joined.
2. "The tick" k_t of a window = the last multiple of 5 strictly below the first unsafe step k*: k_t = 5 floor((k* - 1) / 5). So k* = 1 to 5 gives k_t = 0 (the row of the window origin, with a_m = 0 and g0 = the label gap at step 0), k* = 6 to 10 gives 5, and so on. i = k* - k_t, 1 to 5 steps.
3. A window whose rule ticks 0, 5, ..., k_t are not all in the log, or whose row at one of these steps is not unique, fails control w1 (nothing is dropped silently). Several rows with one (ci, t0, k) and all of the fields read equal count as one row; with differing fields the row is ambiguous (w1 fails). Rows of windows outside the pinned grid are cut.
4. Join: log row to window by (ci, t0) = (dump `clip_index`, `ws`) of the pinned grid windows; the unsafe windows and their first unsafe steps k* are the tool of card ADD135's (`summarize`, `first`, 1-based; unsafe windows = its `sel`: model unsafe and the logged driver not unsafe).
5. Engine values at step 0 (the engine has steps 1 to 30): a_m(0) = 0, g_m(0) = label gap of frame 0 (the engine's G[:, 0]). v_m(k* - 1) at k* = 1 is the dump's `v0` (the engine has no step 0 speed); for k* >= 2 it is the engine's step speed of step k* - 1.
6. a_m(k), g_m(k) at k >= 1 = the engine's (`headway_read_r2.progress`, and `step_arrays` of the tool of card ADD135); P(k) = a_m(k) + g_m(k). e_L uses the engine's P at the tick, the logged v_L; e_X uses the logged g0 (as control w2 of the card says), not the engine's g_m(k_t). Cap = max(3.0, 1.2 v_m(k* - 1)). S = cap - g_m(k*).
7. Rule on at the tick = `active` and `present` both true. R1 and R2 are over all unsafe windows (a window with the rule off counts as not on, and as not braking: its `sat_exec` is read as logged); R3 and R4 over the windows with the rule on. R3 = sum of e_L / sum of S over these windows, bootstrapped as a ratio of episode sums; draws with a non-positive denominator are skipped. R4 = share with e_L strictly larger than e_X. n of R3 and R4 = the number of rule-on windows.
8. Bootstrap: episode units from the engine, `default_rng(137).integers(0, n_ep, (2000, n_ep))` shared by every measure (the tool of card ADD135's `make_draws`, `share_read`); 95 % interval = percentiles 2.5 and 97.5.
9. Beside (no name): medians over the rule-on windows of S, e_L, e_X, i (and of S, i over all unsafe windows); share of rule-on windows with the lead's mean speed over the interval, (P(k*) - P(k_t)) / (0.2 i), more than 0.5 m/s below v_L (strict); share with a negative e_X (rule-on); share with the tick at step 0 (all unsafe windows); R1 to R4 per model seed as plain values (nan where undefined).
10. GEc: the same four measures with intervals, beside only. Its g0 is the camera gap, P is read with the label gap; the third part e_G = g0 - g_m(k_t) (label gap at the tick) is printed beside (median, share positive); for GEc the identity read by w2 is S = e_L + e_X + e_G, and w3 reads e_X + e_G = S; the g0 equality of w1 is read for RLc only (for GEc only the logged arc is compared).
11. Names: clauses of section 4 evaluated on the intervals (a non-finite interval makes its clause false: MIXED, RULE-OFF-IN-PART, DOES-NOT-BIND); FORECAST is tested before EXECUTION (an interval exactly [0.5, 0.5] reads FORECAST). Two routines derive the names and must agree, else the tool refuses.
12. w0: the tool of card ADD135 hashes (CR removed) with the prefix 46be1fad5df31db3; its own identity control `ctl_u0` reads PASS on the eight runs (rates of RLc per model seed and pooled, GEc pooled, tolerance 1e-4); the subject's unsafe counts per model seed are 22, 19, 22, 20; its second routine gives the same first unsafe step in every unsafe window of the eight runs.
13. w1 reads every tick 0 .. k_t of every unsafe window of the eight runs: the logged a_m within 1e-3 m of the engine's; for RLc the logged g0 (where finite) within 1e-3 m of the engine's g_m. A rule-on row with a non-finite g0 or v_L is a join problem. w2 and w3 read the windows with the rule on (tolerance 1e-6 m, at least one window): w3 builds the realised speed from the engine's P and substitutes it for v_L in the same function that makes the measures.
14. w4: each test output (dev, pod): last non-empty line `N passed` (N > 0), no failed or error count, no FAILED or ERROR line, names `test_read_rulelog10k`, path without a component `kit` and not inside the tool's folder. w5: 141 `ep*.npz`, `T1_DONE`, the tick log and the later-look log for each of the eight runs (the later-look log is counted because the rule rate is 5).
15. No clip or episode id is printed or written. Outputs never overwritten (rc 3). Inputs hashed in the controls file: this tool, the tool of card ADD135, the engine files, join, grid, both test outputs, each `T1_DONE`, both rule log files of each run, and one aggregate sha256 over the dump files of each run.
