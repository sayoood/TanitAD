## What the card was built to read, and how
* Windows: the 1,948 windows of `LATENTS_CTX_<ARM>_R1.npz`, pack `leadsup/read/eval_pack.npz` (same order, checked). Frame f of a window = state-file frame / cache step `g0 - 4 + f`; t = frame 4; t + 2.0 s = frame 14. Folds = the pack `fold` (MEASURED: equals `w_fold` of the R1 file; 5 folds of 393/392/393/392/378 windows; 139 episodes, each in one fold, refused otherwise).
* Imagined state: stack rollout from the state of frame 4, 10 steps, logged `act_scaled`, the predictor's own context (3 for G).
* **Which banked file holds that rollout (MEASURED 2026-11-15 on G_s0, 200 windows, the real G_s0 checkpoint `spatial/ckpt/G_s0/ckpt_last.pt`):** `roll_states` with context 3 equals `LATENTS_CTX_G_s0_R3g.npz` `pred_2s` to 1.9e-5 (max abs), and `_R1` to 1.2; with context 1 it equals `_R1` to 2.2e-5 and `_R3g` to 1.2; `_R3h` (a third variant) differs from both by 0.49. So `_R1` = the context-1 rollout, `_R3g` = the context-3 rollout (the one the tool computes), `_R3h` = another variant. k5 uses `_R3g` (`--banked-roll`). The file `_R1` is used for the WINDOW LIST (ids, folds) in k6, as in imaghead. Probe: `work/probe_k5.py`.
* Tokens: cell tokens of the 1,024-d cache grid, per cell a PCA to 64 components fitted on the frames of the four other folds (mean and covariance in float64, eigenvectors of the covariance, sign fixed by the largest entry). Frames = the unique (clip, step) frames covered by the 16 frames of the 1,948 windows (MEASURED 9,460, equals the bank of the pack).
* Map: ridge from the 640-d state of a frame to the 40x64 targets of THE SAME frame, fitted on all unique frames of the four other folds. Intercept by centring. Penalty = `lam_rel x trace(X'X)/640` with `lam_rel = 0.01` (**departure: the card does not give a penalty; fixed here before any data, logged in the dump json; not tuned**).
* Skill = 1 - SSE/SST over frames, cells and components, with SST against the mean of the TRAINING targets (a held-out skill that the training mean already reaches is 0). k2 numbers: `skill_train` (all training frames) against `skill_heldout` (all held-out frames), and `skill_heldout_present` (frame 4 of the held-out windows, true present state on present tokens).
* Errors per window and cell (sum over the 64 components of the squared difference in PCA coordinates): present state, imagined state, true future state, each mapped and compared with the true tokens of frame 14. True token change = squared distance between the PCA coordinates of frames 4 and 14, per cell. L3 distances = squared distance of the present / of the imagined state to the true future state per cell of 16 numbers.
* D = error(present) - error(imagined); headroom H = error(present) - error(true future state). Per window the mean over the cells of the set (all 40, or the 10 moving ones; ties by the lower cell index); per seed the mean over the windows with an episode-cluster bootstrap (B 2,000, rng 0); pooled = mean of the per-seed values, interval = the two-level draw (`boot_plan`: seeds with replacement, then episodes inside each drawn seed). Share of the headroom = ratio of the pooled means (interval from the same draws; NaN when the headroom is exactly 0). D per grid row (all cells of the row). Pair: the same draw for both arms, paired on identical windows; refuses if windows or moving cells differ.
* Names: as the card; "the two-level interval lies above 0" = its lower bound > 0 and each seed's point value > 0. `RR-IMAGINES-TOKENS-BETTER` is named only for the pair RR minus G, only if both arms passed all controls. No name when a control fails or runs on one seed only (`needs both seeds`).

## Controls and where each is measured (each has a deliberate regression in the tests that goes RED)
* k1 (pod computes, reader checks): the whole state table permuted across frames (fixed permutation), fit on the permuted training pairs, applied to the permuted held-out states; held-out skill <= 0.02 in every fold. Mutation: identity permutation (`mutate="identity_perm"`) -> RED.
* k2: per fold `skill_train > skill_heldout` and `skill_heldout_present > 0`. Mutation: held-out skill computed on training frames (`mutate="skill_in_sample"`) -> RED. Mutation: a present skill of 0 -> RED.
* k3 (reader): the present error given as the imagined one: every episode sum of D exactly 0 (all and moving). Mutation: no substitution -> RED (also blocks the name end to end).
* k4 (reader, known positive): the true-future error given as the imagined one: D equals the headroom exactly (bit equality of the episode sums) and the pooled two-level interval of D (all, moving) lies above 0. Mutation: a world where the true future equals the present (flat) -> RED (equality holds, the interval does not lie above 0).
* k5 (pod computes, reader checks): max abs difference of the tool's rollout to `pred_2s` of the banked file <= 1e-4 (the card's bar). The dump also stores the difference of the assembled frame-4 and frame-14 states to the banked `z0` and `true_2s` (state assembly check). Not run (no `--banked-roll`) counts as FAIL. Mutation: a banked rollout shifted by 1e-2, end to end through the pod script and the reader -> RED, name withheld. On the tiny model the difference is 1.2e-6 (float32 chunking).
* k6 (reader): ids, order, count, folds and episode set equal those of the R1 window list (`--ref-windows`). Not run counts as FAIL. Mutations: reversed order, one window fewer, shifted folds, end to end with another-order list -> RED. **Departure:** the card says "windows ... equal those of the r-b read"; the r-b read's floor file `OOF_RB_G_s0.npz` holds 1,809 windows (a subset, same order, MEASURED), the 1,948 are the R1 list, and the card says 1,948, so the R1 list is the reference. The fold of the floor file (`w_epi` mod 5) is NOT the fold of the windows (agreement 17 %, MEASURED), so it is not used.
* Control of the selection: the selection function takes `eid, g0, V, G15, panel` only (test by signature and source scan; mutation: a function with a model input -> RED).

## Decisions and departures from the card (for the lead's note before data)
1. Ridge penalty fixed (above). 2. Targets: the tokens are the 1,024-d cache tokens (the grid "the model sees" before its adapter), PCA 64 per cell; the token change and all errors are in PCA coordinates. 3. L2 colours: ONE basis for all cells (three leading eigenvectors of the cells' pooled covariance, fitted on the training folds), applied to the true tokens of t and t + 2.0 s and to the three decoded grids; one colour scale per window row, symmetric diverging scale for the change tiles. The tiles of L2 show the grids READ FROM THE STATE (present / imagined / true future state through the same map); the true tokens appear only as the change of the truth. 4. L1 (decoded pixel tiles of the earlier reads) is drawn as an empty tile with the reason: the earlier panels are composite pictures and this version does not crop them. 5. L4/L5 read the `imaghead` dumps: lead head at present, imagined 1.0 s and 2.0 s, true 2.0 s; the kinematics line = the d = 0 imagined gap - 0.5 d T^2 (as `imag_read.h2_arrays`). 6. Panel colours are stored for the windows of `--panel-windows` only (the sheet shows an empty tile with the reason for the others). 7. `lv2_pod_tokens.py` reads the state file of `extract_states.py` (as imaghead does), not the cache for the states.
8. Memory: the tokens of the 9,460 frames go once to a float16 memmap (~0.8 GB on disk at F = 1024, in `--workdir`); the per-cell covariances are float64 (0.34 GB). Not measured at full size on this box (no real run, by the card's rule: no data before the lead's note); the tiny runs are the only timings.
9. Frames (L0): decoded with the earlier prep code (raw frame 2 g, area to 64 x 160, uint8). The step alignment `cache step = grid step` is inherited from latvis (R1) and from the identity pack g0 - 4 = panel g0; it was not re-verified against the pictures.
