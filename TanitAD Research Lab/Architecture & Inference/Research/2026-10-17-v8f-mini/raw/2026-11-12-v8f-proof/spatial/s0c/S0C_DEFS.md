# S0C_DEFS (PREREG_V8F_PROOF_ADD12, note N5, stage 0c). Every choice the note leaves open, fixed before any number on true labels.
Tier T0: a world-model diagnostic, never driving performance. CPU only (CUDA_VISIBLE_DEVICES=-1). Code: `s0c_read.py` (this folder); it imports `spatial/s0/s0_read.py` (load_data, mean_token, mean_state, grid_state, cell_block, pca_basis, fit_probe, planted_setup, permute_within_fold, e_floor_ra, single_r2, the constants) and, through it, `res/resprobe.py` (make_folds, boot_counts, auc_pooled, r2_pooled, ep_stats_r2, boot_r2, diff_row, ci). Stage-0 rules R1 to R19 (`spatial/s0/S0_DEFS.md`) apply wherever this file is silent. The note and `spatial/s0/` are not edited.

C1 Pair index. Rows are the stage-0 bank rows (R2: bank frames of `res/cache/frames.npz` with a finite 8-column ego vector E; `load_data(False)`, 139 episodes). A pair is a row i = (clip, g) for which the rows (clip, g+10) = rk and (clip, g-5) = rm both exist, and the lead gap (the banked `lead_gap`, metres) is finite at i and at rk. All such pairs are used, not only the 1,809 eval windows. The index is built from the clip name and frame number of the bank rows (dictionary on (clip, g)), never from the window arrays `ri0` / `rik`. Counts printed: pairs with the three rows, pairs used, pairs per fold, episodes with pairs.
C2 Target. d = gap(rk) - gap(i), metres, untransformed. Persistence predicts d = 0.
C3 Folds and states. Row folds are `RP.make_folds(episode of each bank row, k=5, seed 0)` (R4). The fold of a pair is the fold of its episode (fold of row i). Per fold, on the bank rows of the training folds only (all of them, no label, R5): S0g = per cell 16 PCA directions of the 1024-d token, 40 cells concatenated (640 numbers); S0m = the mean token over the 40 cells, 128 PCA directions. Both come from `grid_state` / `mean_state` of the stage-0 module and are projections of every bank row, so a pair's states at g, g-5 are row lookups. Every fitted object (PCA, scaling, probe, penalty) sees training-fold pairs / rows only.
C4 Ego block. The 8-column ego vector E at g, at g-5 and at g+10: 24 numbers per pair, given to every arm and alone to the floor E. It is z-scored per column on the training-fold pairs (std + 1e-9). In an arm with a state it is then multiplied by the square root of the mean column variance of that state (at g) over the training-fold pairs (the S0 R6 scaling), so that no block dominates the single global scale that `fit_probe` applies. In arm E it is not multiplied.
C5 Arms (columns, in this order). H-g = [S0g(g), S0g(g) - S0g(g-5), ego block] (1,304 numbers); H-m = [S0m(g), S0m(g) - S0m(g-5), ego block] (280); N-g = [S0g(g), ego block] (664); E = [ego block] (24). The state difference is not rescaled (unwhitened scores, as in stage 0).
C6 Probe. The stage-0 `fit_probe` (R7: ridge and RBF kernel ridge, the better by validation error on an inner episode split of the training pairs, kernel ridge on at most 3,000 training rows, one global feature scale), fitted on the training-fold pairs with target d, seed 0 + fold, applied to the test-fold pairs. The five out-of-fold predictions are pooled.
C7 Skill and bootstrap. skill = 1 - sum (d - d_hat)^2 / sum d^2 over all pooled out-of-fold pairs (persistence gives exactly 0). The plain R2 (stage-0 `r2_pooled`, around the mean of d) is printed beside it. Interval: episode-cluster bootstrap, `RP.boot_counts(n_ep = 139, B = 2,000, seed 0)` (B = 200 in smoke): the episodes are resampled with the models held fixed and the two pooled sums (sum d^2 and SSE) are recomputed from per-episode sufficient statistics. ONE draw is shared by every arm and every difference. A difference is the difference of the two skills on the same draws; "excludes 0" is the lower end of the 95 % percentile interval above 0. Episodes without a pair add nothing.
C8 Printed with every number: n pairs, n episodes, tier T0, the estimator, and the sentence "a world-model diagnostic, never driving performance". Four-family line: LONGITUDINAL, LATERAL, TACTICAL not measured by this read; STRATEGIC: PAUSED (PI item 25). Also printed: std(d), mean(d), and the share of pairs with |d| above 2 m. The three differences of the note (H-g minus E, H-m minus E, H-g minus H-m) and H-g minus N-g are printed with intervals.
C9 Outcome names exactly as the note writes them; "above 0 and its interval excludes 0" is read as point difference above 0 and the lower end of its interval above 0. Per state s in {g, m}: S0-CHANGE-READ if skill(H-s) minus skill(E) qualifies; else S0-CHANGE-EGO if skill(E) is above 0 with the lower end of its own interval above 0; else S0-CHANGE-FLAT. Pair: GRID-ADDS-CHANGE if skill(H-g) minus skill(H-m) qualifies, else GRID-EQUAL-CHANGE. History: HISTORY-ADDS if skill(H-g) minus skill(N-g) qualifies, else HISTORY-EQUAL.
C10 Control order and exit. Controls are printed first. If any of k1 to k4 fails, the numbers are written to RESULT_S0C.json, no outcome name is written to any file or to the log, and the exit code is 2. Exit 0 only when all pass.
C11 k1. The targets are permuted within fold (stage-0 `permute_within_fold`, seed 1, among the pairs of the fold) and all four arms are refitted through the same code path. Every skill at or below 0.02.
C12 k2 (planted moving object, label free). Cell c = a fixed cell of the 4x10 grid, row and column drawn with seed 8, the column from 1 to 8 so that it is never a border cell (the left neighbour c-1 and the right neighbour c+1 lie in the same grid row). Vector v = the stage-0 f5 vector: the unit direction of seed 5 times the median token norm (`planted_setup` field `median_token_norm`; it is the field of stage 0, 8.3 on the real tokens). `side` per pair from seed 9: 0 for a random half (object at g-5 in c-1), 1 for the rest (c+1). In EVERY pair, at frame g, v is added to the token of cell c; at frame g-5, v is added to the token of cell c-1 (side 0) or c+1 (side 1); nothing else is touched. Target = side. The PCA of the three touched cells (16 directions) is refitted on the stack of the frame-g tokens and the frame-(g-5) tokens of the TRAINING-fold pairs (planted tokens included); the same basis projects the test pairs. The mean token gets v / 40 added at both frames in every pair (the same shift for both sides, as in R18); its PCA (128 directions) is refitted on the stack of the two frames of the training-fold pairs. Probes: `fit_probe` on [state(g), state(g) - state(g-5)] for the grid (touched cells replaced, other cells as in C3) and for the mean; and on state(g) of the grid alone. Pooled out-of-fold AUROC. Bars: grid two frames above 0.95; mean two frames at or below 0.60; grid one frame at or below 0.60.
C13 k3 (alignment). "Exact" = bitwise equality (`numpy.array_equal`, no tolerance). Every pair is re-derived from the RAW banked arrays (`frames.npz` beid, bg, E, lead_gap) by the key (clip, frame), independently of the row indices that built it: its 24-number ego block equals the concatenated raw E at (g), (g-5), (g+10); the two gaps equal the raw gaps at g and g+10; the clip is the same for the three rows and the frame offsets are exactly +10 and -5. Zero mismatches of any kind. Added check (token side): for 30 random pairs the stored token tensor of the row at g equals the cache row g of the clip file (exact). Both must read zero for k3 to pass. In smoke the gaps compared are the as-loaded banked gaps (the permuted copy only feeds the targets).
C14 k4. The stage-0b r-a numbers are reproduced by the same loaded data and the same code path as `S0.process_fold` (R8): grid gap = the stage-0 probe on S0g alone (bank rows of the training folds with a finite gap, seed 0 + fold) pooled R2 over the gap rows; ego = `e_floor_ra` (best of P1, P2, linear). "To 4 decimals" = the number rounded to 4 decimals equals the reference (grid 0.3981, ego 0.1327). Not run in smoke (permuted labels).
C15 Resumption. Per-fold results are stored in `stages/foldK.npz` with a signature (rows, pairs, smoke flag); a rerun resumes finished folds. Smoke stores nothing.
C16 Smoke. 12 episodes (`load_data(True)`), the lead-gap labels permuted across the finite rows with seed 11 BEFORE the pairs are formed into targets (the finite positions are unchanged, so the pair set is the real one); B = 200. It prints shapes, counts, timings, k2 and k3 only; the arms and the bootstrap run for timing and a format check of the verdict writer, and no skill of permuted labels is stored or printed.

## Departures from the note's wording (each a reading choice, not a change of the question)
D1 (C4) The ego block is z-scored and, in arms with a state, rescaled to the state's mean column spread; the note says only "the ego block".
D2 (C12) The cell is chosen by this file (interior, seed 8); the note says "one fixed cell" with neighbours. The vector is the stage-0 f5 vector (direction seed 5, size median token norm).
D3 (C12) The PCA of the planted cells and of the mean token is fitted on the stack of both frames of the training pairs, not on the bank rows: the plant is a property of the pair, so it exists only at pair frames.
D4 (C9) "Interval excludes 0" is the lower end above 0 (the stage-0 rule R12).
D5 (C11) k1 permutes d among the pairs of each fold (the note: targets permuted within fold).
D6 (C14) "4 decimals" is read as rounded equality, which is a bar of 0.00005 around the reference.

## Named gaps
G1 Linear read of untrained states: a negative is about this read only. G2 Pairs overlap inside a clip; the bootstrap carries the dependence, not the training variance (one seed of the states). G3 The kernel-ridge candidate of the probe uses a fixed random subsample; its effect is not separately measured. G4 k4 depends on the same threading as stage 0 (4 threads); a rounding miss at the fourth decimal would stop the run by design.
N6 Stage 0d (LEAD rule, note `PREREG_V8F_PROOF_ADD12_N6.md`, written after stage 0c was read and before any 0d number). `PAIR_RULE = "continuous"`: a pair is used only if the lead gap is finite on all 11 frames g .. g+10 and no step between consecutive frames exceeds `STEP_MAX_M` = 3.0 m in absolute value; `"all"` reproduces stage 0c. The count of pairs removed is written to the result. Nothing else changes.
