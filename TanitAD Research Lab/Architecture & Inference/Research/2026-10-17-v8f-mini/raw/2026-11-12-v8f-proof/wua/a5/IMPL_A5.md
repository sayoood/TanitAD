## 2. Camera model and cell mapping (cited sources)
* Cache = `local256` (cache `manifest.jsonl`/`runs.jsonl`: `--src-geom 256`): 256 x 640 cylindrical front-wide, `f_ref = 320 / radians(60) = 305.577` (TRAPS.md "pinhole FOV formula is wrong on a cylindrical projection": column LINEAR in azimuth, 120 deg). Not the pinhole formula.
* Rig -> camera: per-clip front-wide mount (qx qy qz qw, x y z) from `C:/Users/Admin/tanitad-data/add203/out/refcv8_train4572_eval139_extrinsics.json` (source: PhysicalAI-AV `sensor_extrinsics`; mean camera height 1.35 m, camera 2.14 m ahead of the rig origin, pitch about -0.17 deg per its `_read`), `R_c2v` = `FrontWideExtrinsics.rotation_cam_to_vehicle` formula (pinned tree `physicalai.py:258`), `p_cam = R^T (p_rig - t)`. The camera height and pitch are therefore the clip's own mount, through the full rotation; as the cache builder, no pitch compensation is applied (`cropread/enc/lead_box.py` docstring: elevation 0 is the optical axis). Reused: the angle formulas of `cropread/enc/lead_box.py::cam_angles` (azimuth = atan2(-x, z) LEFT positive, elevation = atan2(-y, hypot(x, z)) UP positive), restated here (that file imports pod-side modules).
* Image coordinates: column x_px = 320 - f_ref * azimuth(rad); row y_px = 128 - f_ref * tan(elevation) (cylinder rows linear in tan(el): `enc_common.rotation_az_el` docstring).
* Pool grid: 4 x 10 cells of 64 x 64 px over the full image (16 x 40 patches of ViT-L/16, 4 x 4 patches per cell; ASSUMPTION: plain mean pooling of the patch field, as `pull_encode_pooled.pool_field` for the 8 x 8 case, `enc_common.py:211-218`; the pool script itself is not local), flattened ROW-MAJOR (cell = 10 * row + column; the same order as `enc_common.py:218`). Column c covers azimuth 60 - 12c down to 60 - 12(c+1) degrees; row r covers y_px 64r .. 64r + 64. If this mapping were wrong, c10 (below) would fail and A5 would read MASK-FAILED: the control is the check on the mapping.
* LEAD cells: the projected bounding rectangle (min / max column x_px and y_px over the 8 corners) of the lead's cuboid; every cell whose rectangle intersects it with positive area (> 1e-9 px^2). Coordinates are clipped to the image; an empty result excludes the window.

## 3. CONTROL cells (card rule)
For every row r the LEAD occupies columns C_r, the mirrored block is {9 - c : c in C_r} in the same row (same number of cells, same rows). The block is moved OUTWARD, as one block, column by column (direction +1 when the mean LEAD column < 4.5, -1 when > 4.5, +1 at exactly 4.5), until it (i) shares no cell with the LEAD cells and (ii) contains no cell that any OTHER agent within 50 m (range hypot(x, y) <= 50 m, centre x > 0, all 8 corners z > 0.1 m) projects onto (same positive-area rectangle rule). A block that leaves columns 0..9 before it is clean has NO control: the window is excluded (not clipped, not relaxed), and counted.

## 4. Masking
* Primary: a masked cell's input token (1024-d, in `batch["feats"]`, the DINOv3 pooled feature that the adapter reads) is replaced by that cell's MEAN token over ALL frames of all eval-141 clips (float64 mean over the ClipStore fp16 features, stored as fp16), computed once (`C:/Users/Admin/wua_work/a5/cellmean.npy`). Beside: ZEROING (the same cells set to 0).
* Which frames: ALL `hmax = 10` history frames of the batch (t-9 .. t), so that whatever frames the planner reads are masked. Each frame uses ITS OWN lead cells and control block (the section 1b/3 rules on that frame's agents), falling back to the current frame's sets when that frame has no lead / no clean control / no agent line. Padded frames (before clip start) take the current frame's sets.
* The probe of c10 sees the current frame t only (its LEAD / CONTROL sets of frame t).

## 5. Read, metric, labels
* Planned speed at 2.0 s: `traj30 = forward_infer(batch)["traj30"]` [B, 30, 2], knot k at (k+1) * 0.2 s; v2 = |0.5 * (P[10] - P[8])| / DT with DT = 0.2 (`D.DT`, `v8f_t1_eval.py:52`): the Catmull-Rom tangent / DT at the 2.0 s knot P[9], exactly how `hermite_frames` turns knots into speed (`v8f_t1_eval.py:97-112`). dv = v2(masked) - v2(unmasked) (m/s).
* Metric per window: m_i = |dv(LEAD)| - |dv(CONTROL)|. Statistic = mean over windows. Interval: paired episode-cluster bootstrap over clips, B = 2000, `np.random.default_rng(0)`, `rng.choice(n_ep, n_ep)` per draw, ratio (W @ sum_i) / (W @ n_i) over per-clip sums, 2.5 / 97.5 percentile. Per seed. Beside (not label): the signed means dv(LEAD), dv(CONTROL), their paired difference, share of windows with dv(LEAD) > 0, the subset with lead gap <= 20 m, and the same under zeroing.
* Label (card): USED = lower bound > 0 at all 3 seeds; NOT-USED = the interval contains 0 at >= 1 seed. A case the card names neither (no interval contains 0, and some interval lies entirely below 0 while no seed fails) is reported as `UNNAMED-BY-CARD (separated negative at seed k)`, no label invented. c10 failing: `MASK-FAILED` (overrides), c11 failing: `INVALID`.
* c10 (manipulation check): P-LIN of card section 1 on TOK-GRID: TOK-GRID = `model._encode({"feats": x})` of frame t, 40 x 256 flattened; per outer clip fold (`wua_a1.fold_of`, 5 folds) a PCA(256, randomized, random_state 0) fitted on the training folds' frames; z-scored on the training rows; logistic regression for `lead_present` (WUA_LABELS) with C chosen by the inner 3-group log-loss of `wua_a1.oof_logit` over `ALPHAS`; all frames of the held-out fold with a finite label train/test as in A1. For each KEPT window (held-out fold) the decision value (logit) is read on the unmasked, LEAD-masked and CONTROL-masked frame t; drop = logit(unmasked) - logit(masked); c10 statistic = mean_i [drop_LEAD - drop_CONTROL], pooled over seeds as the mean of the three seeds' per-window values, paired clip bootstrap as above (same draws). PASS = lower bound > 0. A window enters c10 only if it is in the primary set. Mean-token masking.
* c11: for every kept window one more forward on a batch passed through the SAME masking function with an EMPTY cell list; dv must equal 0.0 exactly (max |dv| == 0.0, bit-identical `traj30`). A synthetic test also checks the cell mapping (a box at known azimuth / elevation) and the empty mask.

## 6. Limits (stated before data)
One corpus, 139 clips with agents; mapping rests on the cylinder + mount + pooling assumption above; the CONTROL is matched by geometry, not by token content (rows differ in what they usually show: sky / road); masking by mean token is out-of-distribution for the adapter to an unknown degree (zeroing is beside for that reason); lead = the nearest in-corridor agent, not necessarily the join's lead agent (condition (a) requires the join to have one). Inference variance: none (CPU, deterministic). Training variance: three seeds, each seed a separate label input.
