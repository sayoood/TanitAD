# GAPS_DEFS: the two NAMED GAP rows of the HIERREP read (HIERREP_DEFS R14 a and b)
Written before `hierrep_gaps.py` computed any metric on any dump, and before any HIERREP dump existed on this box. Every rule below was fixed from the format of the older dumps (`wsp/t1`, same writer, commit 3e264bbf), the lead file and the eval label join, and from the definitions already in the code base. No rule uses a number computed from HIERREP dumps. Tier: T1-kin (kinematic rollout on the model's own actions, logged scene), a diagnostic and never driving performance. Evidence class MEASURED once run. Rows here complete the four metric families; they are not card criteria and move no card bar. STRATEGIC: PAUSED (PI item 25), printed as such and never a pass.

## Inputs (all named, none approximated)
* Dump `ep*.npz`: `g` (logged future [n,30,2], knots at 0.2 s, window-origin ego frame), `cl` (executed T1-kin track, same grid and frame), `ws` (t0, in cache steps of 0.2 s), `eid` = `clip_index`.
* Lead file `E:/Projects/TanitAD-artifacts/v9labels/inputs/lead_eval139.npz` (keys `sha12, k, has, lead, gap, tg, s, v`; one row per raw 10 Hz frame k = 0..199 per clip; `lead` 1 = a lead on the ego's own path within the build range, `gap` = bumper gap in metres along the ego's smoothed path, built by `build_v9_labels.lead_for_frame`). Clip id to rows by `sha12(clip id) = sha256(utf-8 id)[:12]`. Clip id of `clip_index` c = `clip[c]` of `join_eval141.npz`.
* Label join `join_eval141.npz` (`off`, `n`, `has`, `goal_y`, `goal_w`, `lon_cls`; row `off[c] + s` is cache step s of clip c).
* Tick file `ticks/ticks_<tag>.npz` (only for part B): per (window, tick) `t_goal_prob` [22], `t_lon_logits` [7], `ci`, `win`, `tick`, `j`, `age_t`.

## Part A: LONGITUDINAL distance keeping (headway and time gap)
* **A1 Unit.** One unit = one (window, knot k), k = 1..30. Knot k of window w with origin step t0 lies at cache step t0 + k, raw frame 2 (t0 + k). Counted only if the lead file row has `has` = 1, `lead` = 1 and a finite `gap`. A window or episode with no such knot contributes nothing; their counts are printed.
* **A2 Lead track.** The lead is the lead file's own lead (the nearest vehicle in the logged ego's path corridor, as built). Its position is held to the LOGGED scene: it does not react to the rolled ego (logged scene, the same open channel the T1-kin tier names). The lead is represented by its path coordinate: `S_L(k) = s_log(k) + gap_log(k)` in the arc-length coordinate of the logged ego path.
* **A3 Rolled gap.** The rolled ego enters only through its along-path offset from the logged ego at the same knot: `e_k = (cl_k - g_k) . u_k`, with `u_k` the unit tangent of the logged track at knot k (direction `g_k - g_{k-1}`, `g_0 = (0,0)`; if that step is shorter than 1e-6 m the previous tangent is kept, and (1,0) before any, the window origin heading). Then `gap_roll(k) = gap_log(k) - e_k`. A rolled ego ahead of the logged one has a smaller gap. Cross-path offset does not enter; units: metres.
* **A4 Speeds and time gap.** Speed at knot k of a track = `||p_k - p_{k-1}|| / 0.2` (`p_0 = (0,0)`), m/s; `v_log` from `g`, `v_roll` from `cl`. Time gap `tg(k) = max(gap, 0) / max(v, 1.0)` seconds, with the 1.0 m/s floor of the label builder (same formula as lead file `tg`, verified exact there). Logged `tg_log` uses `gap_log, v_log`; rolled `tg_roll` uses `gap_roll, v_roll`.
* **A5 Reported per arm and per episode, as sums and counts** (ratio of sums over units, the estimator of `hierrep_read.read_cell`): (i) mean absolute gap error `|gap_roll - gap_log|`, metres; (ii) mean signed gap error `gap_roll - gap_log`, metres (negative = rolled closer); (iii) mean absolute time-gap error `|tg_roll - tg_log|`, seconds; (iv) the share of units with `tg_roll < 1.0 s` among units where `tg_log >= 1.0 s` (numerator, denominator, share); (v) counts: n units, n windows with a unit, n episodes with a unit, n units with `gap_roll < 0` (rolled through the lead), n units with rolled cross-path offset above 2.0 m (reported, not excluded).
* **A6 Arm difference.** Per seed `d_s` = hierarchical minus flat, per metric, the units set being the logged-defined set (identical for both arms, asserted); two-level bootstrap seeds then episodes, B 2,000, rng 0, label rule R10 of HIERREP_DEFS, n_seeds label gate as in the reader (`INCOMPLETE` flag when fewer than 6 seeds). Lower is better for every row.
* **A7 Alignment check (a1, decides validity).** The median over units of `|v_file(frame) - v_log(k)|` (lead file `v`, the logged ego speed at raw frame, against the speed from `g`) must be at most 0.5 m/s; above it the frame mapping is wrong and the read is NOT VALID.
* **A8 NOT measurable from the dump, with the reason.** (1) Lead behaviour under the rolled ego (a reactive lead): the logged scene replays the logged lead; stated per row. (2) Gap when the rolled ego leaves the logged corridor laterally: only the along-path offset is read; n units with offset above 2.0 m are printed. (3) Windows or knots with no lead in the lead file: no gap exists; n printed. (4) Lead identity or class: the lead file carries no track id. (5) Time gap for a lead beyond the build range: no label.

## Part B: TACTICAL goal-setting (stop-goal decision)
* **B1 Label.** Per (window, tick) row of the tick file, the T head's output at tick n belongs to cache step `s = j - age_t` (sample-and-hold, as the dump writer states). Label row = `off[ci] + s` of the join. Positive: `has` and bit 6 of `goal_y` (STOP_POINT, `v8f_mini.STOP_I = 6`) and bit 6 of `goal_w`. Negative: `has`, bit 6 of `goal_w`, bit 6 of `goal_y` clear. Rows with `goal_w` bit 6 clear, `has` false, or `s` outside the clip are unlabelled and excluded (n printed).
* **B2 Decision and score.** Decision = `t_goal_prob[:, 6] >= 0.5` (the threshold of `v8f_mini_eval.tactical_metrics` and of the earlier STOPDEC read); score = `t_goal_prob[:, 6]`.
* **B3 Reported.** Confusion counts TP, FN, FP, TN; balanced accuracy = (TP/(TP+FN) + TN/(TN+FP)) / 2; AUROC of the score (ties count one half); n rows, n positives, n episodes with a positive. Each arm, all ticks pooled (a row is one decision), and tick 0 alone (executed pose equals the logged pose there, so it is the open-loop decision).
* **B4 Secondary tactical rows (same rows, same labels).** (i) the longitudinal STOP class: the 7-way `argmax(t_lon_logits) == 2` against `lon_cls == 2` (`LON_STOP_I = 2`), rows with `has` and `lon_cls >= 0`, balanced accuracy; (ii) goal macro-F1 over the 22 goal tokens at threshold 0.5 using `goal_y`, `goal_w`, `has` as `tactical_metrics` does (tokens with no positive support drop out, nanmean).
* **B5 Arm difference.** Same engine as A6 (two-level bootstrap over seeds and episodes, B 2,000, rng 0; the statistic is recomputed from the summed per-episode counts of each drawn slot; AUROC from episode-weighted rows). Difference = hierarchical minus flat; higher is better for every B row, so a POSITIVE difference favours the hierarchy; label rule: HIER = all d_s > 0 and A lo > 0, FLAT = all d_s < 0 and A hi < 0, else OPEN.
* **B6 NOT measurable from the dump, with the reason.** (1) The selected tactical goal against a label of one class: the label is multi-hot, so only the token-wise rows above exist; no argmax-selection confusion is defined. (2) The decision at ticks 1 and 2 is about frames seen from the rolled pose, while the label is a property of the logged frame; the pooled row mixes both and tick 0 is printed beside it. (3) Windows whose frames lack labels (`has` false, or stop token not weighted): n printed. (4) AUROC with no positive or no negative in an arm: undefined, printed as NaN with n.

## Controls (the read refuses or marks NOT VALID without them)
* **g1** Shuffled-arm-label control: 20 draws (draw k uses `default_rng(2000 + k)`, bootstrap B 500 per draw), each seed's hierarchical and flat arrays swapped with probability 0.5; every row (A and B) must read OPEN in at least 18 of the 20 draws. The control is NOT-INFORMATIVE (reported, not a pass) with fewer than 4 seeds. The count per row is printed.
* **g2** Identity: the logged track `g` in place of the rolled `cl`: every gap error, signed gap error and time-gap error reads exactly 0.0, and the share row reads 0 of the denominator. Run on the first arm read, per episode.
* **g3** Completeness: 141 `ep*.npz` per arm, every seed named present, the window arrays (`g, ws, eid, clip_index, v0`) bit-identical across arms, tick files present for part B; otherwise the read refuses (exit 3). `--no-card-counts` relaxes only the card window counts and the six-seed label gate, and says so in the output.
* **g4** Alignment check A7.
