# LATVIS_DEFS (PREREG_V8F_PROOF_ADD10). Every choice the card leaves open. Line numbers are in latvis.py unless a file is named.

R1. Windows: the WMACT eval-141 windows with 16 real frames (`latents.pt` ok.all, 1,976), restricted to the 139 clips that have frames here (28 windows dropped; the count is printed). Frame j of window w is grid step t - 15 + j (D.item idx = arange(t - hmax + 1, t + 1), `wm/tree/stack/tanitad/data/v8f_mini_data.py:573-583`; hmax 16). Start frame = window frame 0 (as wmceil/wmstack), so 0.8 s = +4 grid steps and 2.0 s = +10 steps (0.2 s per step). All of them lie inside the window, so no row lacks a full horizon (n reported). Built at `build_ctx` (l.267).
R2. Frame pool: the unique (clip, grid step) frames covered by the used windows (about 10,000 of the 14,035). V1 and the decoder training use the pool, V2 and the panel use the windows. Z of a pool frame = the banked level-1 latent `Z1[tag][w, j]` of that frame; the same frame in different windows gives the same latent (max abs diff checked and written to RESULT meta).
R3. Z = level-1 latent, 128 numbers, `latents.pt` key Z1 (tag M2b_s0 = "Zs0", M2b_s1 = "Zs1"). G = the 4x10 grid of the same frame from `full/feat/LO_r128.i8`: whitened value q*6/127 (`full/feat/pca.npz` scale = 6 sigma / 127 and `fullres_encode.py:169-171`), mean over 4x4 token blocks of the 16x40 row-major map (`pool4x10`, l.53; unit-tested). G uses the same pool frames as Z, so G minus Z is paired.
R4. Frames: `prep` decodes every grid frame (raw frame 2g) with `fullres_encode.load_ep` / `decode` (`full/fullres_encode.py:65`, `:73`), area-downsamples with `F.interpolate(mode="area")` to 64x160, rounds to uint8, writes `frames64.u8` [N,3,64,160] indexed by the encode's row (`index.npz` row0 + g), `prep_done.json` marks finished episodes (resumable, l.235). Image targets are scaled to [0,1].
R5. Decoders (l.116): Z = Linear 128 -> 256x4x10, G = 1x1 conv 128 -> 256 on the 4x10 grid; then four blocks (nearest 2x upsample, conv3x3, GroupNorm(8), GELU, conv3x3) with widths 256 -> 192 -> 128 -> 64 -> 32, then conv3x3 to 3 channels and sigmoid. Inputs are standardised with the training rows' mean and std (per dimension for Z, per channel over rows and positions for G), stored as buffers, so a predicted latent is scaled exactly like a true one.
R6. Training (l.163): L1, AdamW lr 2e-3 (default weight decay 0.01, constant lr), batch 128, at most 20 epochs, early stopping patience 4 on the L1 of an inner split (20 % of the training episodes, `resprobe.inner_split` seed 0, `res/resprobe.py:149`); the best-epoch weights are kept and the decoder is trained on the inner-train rows only (no refit). Decoder seed = fold index (the WM seed is in the source name).
R7. Folds: `resprobe.make_folds(pool clip ids, k=5, seed 0)` (`res/resprobe.py:40`), unit = episode. Every held-out or shown frame is decoded by the decoder of its own fold. Stage files `stages/<src>_<main|perm>_f<k>.npz` hold the outputs of each finished decoder, so a restart skips them.
R8. Skill (l.61): 1 - sum MSE / sum MSE0 over held-out frames, MSE = mean over 3x64x160 of squared error on the [0,1] scale, MSE0 against the mean image of the fold's training frames (all training-fold frames). CI: `resprobe.boot_counts` (B 2,000, seed 0, episodes as clusters), the same draws for every paired difference (`res/resprobe.py:65`). G minus Z = (sum MSE_Z - sum MSE_G) / sum MSE0.
R9. Predicted latents (l.332): learned rollout = `wmceil.level_pack` (`wm/wmceil.py:166`) at level 1, context 1, with the cell list temporarily set to k in (4, 10) (0.8 s, 2.0 s, composed 0.2 s steps, as the banked 2.0 s cell); stacked predictor = `wmstack.stack_features` (`wm/wmstack.py:23`) with `wmceil.cross_fit` (`wm/wmceil.py:105`), inputs (z0, the first k action rows, learned - z0), target zk - z0, prediction z0 + ridge, as `wmstack.py:56-63`. The ridge folds are this read's decoder folds (the card does not fix them). Actions are `wm.scale_actions(A_raw)[:, :-1]` as `wmstack.py:48`. The true future latent is the pool latent at that frame (equal to level_pack's true[1], max abs diff written to RESULT meta).
R10. V2 statistic: per window, pixel MSE against the true frame at start + k of (a) the decoder of the window's fold applied to the predicted latent, (b) applied to the start latent, (c) applied to the true future latent. Mean over windows; bootstrap over episodes of the ratio (sum of per-episode differences) / (windows per episode). Labels per seed and predictor; the 2.0 s outcome needs both seeds, a mixed pair reads IMAGINE-FLAT; headroom not positive with an interval excluding 0 at either seed reads NO-HEADROOM. The learned rollout and the stacked predictor both get a label; the card's "predictor" is read as each of them.
R11. Controls: v1 = one permuted-input decoder per source and fold (inputs permuted across frames inside the inner-train set and inside the inner-validation set, images fixed), held-out skill pooled over folds, bar at most 0.02 for each source. v3 = skill of the fold decoder on its inner-train frames pooled over folds, at least the held-out skill, per source. v2 = the headroom test above; its miss is NO-HEADROOM, not a stop. Exit code 2 when a v1 or v3 control misses; the results and the numbers are still written.
R12. Picture rule (l.82, l.365, l.383): logged speed = `res/cache/frames.npz` E[:,0] at (clip, g0) and (clip, g0+10); logged lead gap = `lead_gap` at (clip, g0) (finite values only). A window is eligible for group A when both speeds are finite, for group B when the gap is finite (the bank covers grid steps 0 to 71; windows end at t <= 71). Group A: 6 largest |speed change|, one per episode; group B: 6 smallest gap, one per episode and never a window already in A; ties by (clip, g0). The list is written to `PANEL_WINDOWS.json` before any decoder exists; a later run must reproduce it. Order on the sheet: group A descending, then group B ascending.
R13. Panels (l.559): PIL, 12 rows x 6 columns of 64x160 tiles, column titles as in the card, row label = the rule value and clip prefix; the predicted-Z column is the learned rollout's 2.0 s latent. `panel_s0.png`, `panel_s1.png` (Z of seed 0 or 1; the G and frame columns are the same) and `*_600.jpg` (width 600, quality 80). `panel/PRIVATE_DO_NOT_LAND.txt` states they hold camera content.
R14. GPU: `fullres_encode.take_lock` / `release` (`full/fullres_encode.py:33`, `:55`) around the whole decoder work when CUDA is present (env LATVIS_NOLOCK skips it for tests). `prep` and the latent predictions run on the CPU.
R15. No train/eval label from this read uses ego state at inference; the decoders see only Z or G. Tier T0.
