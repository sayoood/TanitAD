## Numbered deviations / reading choices (none moves a bar or an outcome rule)
R1 k2 "overrun 0": the banked ORACLE is NOT overrun 0 on the stop windows (`rule/RESULT_RULESHIELD.json`: share 0.0229 at s0, 0.0153 at s1, from windows INFEASIBLE-AT-START). k2 therefore requires equality with the banked values (ADE change to 1e-9 m, overrun share and mean to 1e-9); overrun is exactly 0 only on feasible-at-start windows (reported beside). On a window subset (smoke) k2 cannot reproduce the banked numbers and is marked evaluated=False, not failed.
R2 The flag "probability" is the kernel-ridge score on the 0/1 label (RESPROBE P1 treats binary targets the same way); tau is a threshold on that score.
R3 Inner cross-fitting (q, set choice) reuses the outer fold's unsupervised kernel PCA (fitted on the training windows, no labels); the ridge and alpha are refitted inside each inner fold.
R4 tau uses the in-sample training scores per the card's wording; a secondary tau from inner cross-fitted scores is reported (hit and false-positive rate only, not a card outcome).
R5 Ego-only set E uses the same linear ridge on the 8 standardised features (P1 only, as the card says "the RESPROBE kernel ridge probe"); RESPROBE's MLP P2 is not run. This may make E a weak baseline for FLAG; stated, not corrected.
R6 DIST best set = lowest median abs error over all five sets (E included); "better than both floors" = paired episode-cluster bootstrap of the median-abs-error gain over the constant floor and over E with the 95 % interval above 0 (if the best set is E it cannot beat E). Label order: ABSENT if > 8.0 m or not better; COARSE if 5.0-8.0 m and better; USABLE if <= 5.0 m and better. The DIST outcome needs both plan seeds; the weaker label is reported.
R7 SHIELD outcome per plan seed; CUE-PROBE-GAINS needs both seeds; CUE-PROBE-COSTS if the non-stop bar fails at both seeds; everything else is NO-GAIN (per-seed labels printed, so a split is visible). The "size >= 0.30 of the ORACLE gain" uses |PF-PD delta| / |OF-OD delta| from this run (equal to the banked ORACLE at k2).
R8 Fold-seed spread: the bootstrap intervals are computed for fold seed 0 only; fold seeds 1-4 give point estimates (AUROC, median error, coverage, PF-PD stop 2-6 s and non-stop 0-6 s ADE change).
R9 k1: FLAG labels permuted over all labelled windows (across episodes), DIST labels permuted over the stop windows; pass = AUROC within 0.5 +/- 0.05 for all five sets and no set better than the constant floor by the paired interval. k4: the late-token arm uses cache row ws + 10 (2.0 s) for V40 and V160 (own Gram matrices), E at the now-frame; pass = the guard raises on those rows and AUROC of V40+E and V160+E rises above the real one (point estimate).
