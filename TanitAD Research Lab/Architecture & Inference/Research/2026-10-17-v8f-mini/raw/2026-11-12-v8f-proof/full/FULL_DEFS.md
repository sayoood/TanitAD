# FULL_DEFS (PREREG_V8F_PROOF_ADD9): reading choices the card leaves open

Code: `fullres_probe.py` (this folder). Reused by import, unchanged: `res/resprobe.py` (make_folds :40, kpca_fit :110, fit_p1 :156, fit_p2 :164, e_block :204, run_probe_cv :209, boot_counts :65, ep_stats_r2 :71, boot_r2 :80, boot_auc :86, diff_row :103, inner_split :149, r2_pooled :49, auc_pooled :55), `cue/cueprobe.py` (make_idx_draws :128, boot_median_gain :136, cue_d0 :103, rs() :60, to_py :522). Banked controls: `res/RESULT_RESPROBE.json` metric["GAP|V40+E|P1"], ["LEADP|V40+E|P1"].

R1 Unit table. Rows = bank frames (beid, bg of `res/cache/frames.npz`, finite E only, as resprobe cmd_run :280) followed by the first-tick windows (clip, ws of `cue/cache/frames.npz`, E there). Memmap row = row0[clip] + g (g = bank bg, or window ws). Rows whose clip is absent from `feat/index.npz`, or with g >= T[clip], are dropped; counts are in RESULT_FULLRES.json (config.table.dropped).
R2 Folds. `RP.make_folds(beid_of_kept_bank_frames)` (seed 0, 5 folds) = the folds of addendum 1, mapped by clip to the window rows. A window clip that is not in the bank fold map (none expected) takes fold i mod 5 over the sorted missing clips; the count is reported.
R3 Stop labels. STOPFLAG = `stop_hit`, valid where `has` (2,365 of 2,399 before dropping); STOPDIST = `stop_shield.rest_arc(plan, or_xy)[0]` on plan seed 0 on the 131 stop windows, through `cueprobe.rs().load(0)` (heavy import: torch + the res/tree tanitad; the job sets the cue job's PYTHONPATH). Cached in `kern/stoplabels.npz`. CUEPROBE fitted a per-plan-seed distance; here plan seed 0 only.
R4 P1 on the unified rows: kernel PCA rank 256 is fitted on all training-fold rows (bank + windows) per set; the +E block and kernel ridge are RESPROBE's; each target is fitted on its own valid training rows (STOPDIST on the stop windows only). Linear kernel on the flattened TRUE coordinates q * scale, float32 GPU Gram in 384-row blocks, saved as `kern/K_<set>.npy` (pooled sets: the 4x4 / 2x2 mean of q, times scale, equals the mean of the true coordinates).
R5 Pooling order. L40 = mean over 4x4 blocks of the 16x40 token map (row-major block index rb*10 + cb); L160 = 2x2 blocks (rb*20 + cb); C640 = HI rows 5..20, columns 12..51 (row-major, 16x40); pooled sets are stored float16, U640/C640/H1664 int8.
R6 P3. Whitened input q*6/127; MLP 128 -> 64 GELU; per target a linear score and a linear value on the 64-d token feature; softmax over tokens per target; + linear(standardised E, 8 -> 6). One network per (set, fold, seed) over all six targets with per-target row masks; loss = mean of the per-target masked mean losses (BCE for LEADP and STOPFLAG, MSE on training-standardised GAP, NEAR, COUNT, STOPDIST); AdamW lr 1e-3, weight decay 1e-2, batch 256, at most 40 epochs, early stopping (patience 5) on the inner split = 20 % of the training episodes (`RP.inner_split`, seed 0) with the same masked loss; best-epoch weights; 3 init seeds (1000*fold + s); test outputs averaged (logits for binary, original units for regression). Rows with no observed target are not used. The attention probe sees all rows (bank and window) in one batch stream; windows are 20 % of rows.
R7 E baseline. Per target the better (pooled metric on the out-of-fold predictions) of RESPROBE's P1 ridge on the 8 standardised features, RESPROBE's P2 MLP, and a plain linear (regression) or L2 logistic (binary) fit; the choice per target is stored in RESULT_FULLRES.json (E_baseline). The same E vector is the reference for P1 and P3 pairs. STOPDIST uses -median|error| as the selection score.
R8 Metrics. Pooled over the five out-of-fold predictions: R2 (GAP, NEAR, COUNT), AUROC (LEADP, STOPFLAG), median absolute error in metres on the stop windows (STOPDIST; R2 beside). Per-fold values stored. Pair difference a minus b: R2 / AUROC difference with `RP.diff_row` on the shared bootstrap counts; STOPDIST: median|err|(b) minus median|err|(a), episode-cluster index draws over the stop windows (`CP.make_idx_draws`, B 2,000, seed 0), positive = a better.
R9 Outcomes. "Separated" = 95 % interval excludes 0. A fine-over-coarse claim (P4a-full, P4a-res, INTERFACE-LIMITED) = P3 separated above 0 and P1 not separated below 0. INTERFACE-LIMITED: the better (P3 point R2) of U640+E and H1664+E beats L40+E by >= 0.10 with that rule; ENCODER-LIMITED: neither fine set is separated from L40+E in either direction; else INTERFACE-PARTIAL. Stop cue: CUE-FOUND if any of U640, C640, H1664 (+E) is separated above E on STOPFLAG AUROC (P3); DIST-FOUND if the P3 best of them by median error is separated better than E on STOPDIST; both labels can be printed; none = CUE-ABSENT-FULLRES.
R10 P4c. STOPFLAG AUROC gain of C640+E over E on (stop windows with rest distance < 40 m + all labelled non-stop windows) versus (stop windows >= 40 m + all non-stop windows); paired bootstrap of the difference of the two gains; n of stop windows in each group printed.
R11 Controls. f1: P1 on the cached K40 (rows with finite E), GAP R2 V40+E vs banked to 1e-6. f2: read from `feat/F2_RECIPE.json`. f3: P1 on L40+E of the unified rows vs the banked V40+E (GAP 0.05, LEADP 0.03). f4: every target permuted within fold among its valid rows (seed 4), P3 on L40 and U640; bars R2 <= 0.02 (GAP, NEAR, COUNT, STOPDIST) and |mean per-fold AUROC - 0.5| <= 0.06 (LEADP, STOPFLAG). f5: a fixed random vector (seed 5) of the median whitened token norm added to one random LO token position (of 640) in a random half of ALL table rows; target = planted; P3 U640 >= 0.95; P1 on the planted U640 Gram and P3 on L40 (the vector divided by 16 on the covering pooled token) printed beside. f3 failing: INVALID-AS-DESIGNED written into the outcomes, exit 2, all numbers still written. f4 or f5 failing: exit 2, miss stated with its numbers.
R12 TEMPORAL. Runs after the outcomes when GAP is ENCODER-LIMITED or UNPOOL-FLAT: P3 on U640 of frame g with frame g-5 (previous-frame tokens read from memmap row - 5 of the same clip), 1,280 tokens, a 129th channel = frame bit (0 current, 1 previous); rows with g < 5 are dropped from training and testing (n reported); TEMPORAL minus U640 on the common rows, using the main U640 predictions restricted to those rows (the main U640 networks were trained on all rows).
R13 Controls are evaluated in the order f1, f2 (CPU, before any GPU work), then f4/f5 P3 fits right after the U640 and L40 sets, f3 after P1; they are printed first in the verdict. The run continues after a control miss so that the numbers are written; the exit code carries the miss.
R14 GPU. Every CUDA section (token sets, Grams, P3 fits, TEMPORAL) holds the shared lock through `fullres_encode.take_lock` / `release` (released in `finally`); P1 and the bootstraps run on the CPU after the lock is released. Stage checkpoints: `stages/<tag>_f<fold>_s<seed>.npz` (a restart skips finished fits); Grams are skipped if their file exists.
R15 Bootstrap B 2,000 (200 in smoke), seed 0, one shared draw for every pair.
