# HIERREP_DEFS: reading choices for PREREG_V8F_PROOF_ADD11 (card sha256 94647519b965...29d1c, frozen, not edited)
Written before `hierrep_read.py` existed and before any arm output existed. Tier T1-kin (kinematic rollout on the model's own actions, logged frames, a diagnostic and never driving performance). Evidence class MEASURED once run. Nothing below moves a card bar; each item fixes something the card leaves open.

## Data
* R1 Dump layout: `<T1 root>/<ARM>_s<S>/dump_<ARM>_s<S>_m10_causal_heads/ep*.npz` (141 files, sorted by name), written by `v8f_t1_eval.py run ... --replan-steps 10 --nav deadreckon --scene logged --schedule periodic --limit causal --dump-ticks ... --dump-heads` with tag `<ARM>_s<S>_m10_causal_heads`. Keys read: `g` (logged future [n,30,2], 0.2 s knots, ego frame), `cl` (T1-kin executed track, same grid), `eid`, `ws`, `clip_index`, `v0`. Windows, `g`, `eid`, `ws`, `clip_index` must be bit-identical across every arm and seed read (asserted); a mismatch aborts the read.
* R2 Completeness (control r5): an arm is read only if its dump has 141 readable files AND `<runs root>/<ARM>_s<S>/summary.json` has `done: true` and `steps` equal to 19,164 (Stage 1: HIER, FLAT) or 3,000 (Stage 2: DAG, FLATDAG). A seed enters the read only if all four of its arms pass; both stages use the same seed set S*. If |S*| < 6 the card's "all six d_s" cannot hold: every label becomes OPEN and carries the flag INCOMPLETE (n seeds named). The flag never turns a miss into a pass.
* R3 Parameter count (control r3): `levers.n_params_trainable` of HIER_s and FLAT_s summaries (and DAG/FLATDAG) must be equal within a seed pair and equal to 7,214,495 (the card's source value). Mismatch = control failed.

## Quantities
* R4 Per-window ADE6 = mean over the 30 knots of ||cl - g||. Tactical-band ADE (the card's "tactical-band ADE", knots 11 to 30, t = 2.2 to 6.0 s, index 10:30) = mean over those 20 knots. Operative band is not read.
* R5 Window classes: from the LOGGED future `g` only, with the function and thresholds of HIERWHERE (HIER_DEFS.md section 2, copied verbatim: STOP 0.5 m/s, +/- 2.0 m/s, +/- 10 deg; joint = lon x lat; SELECTION-CRITICAL = not (KEEP, STRAIGHT); BULK = KEEP/STRAIGHT; ALL = every window). Expected counts at the card: 2,399 windows, 141 episodes, 1,305 critical, 1,094 bulk; the reader asserts them (`--no-card-counts` only for synthetic tests) and a mismatch is a control failure.
* R6 d_s = mean over the class windows of [ADE6(hierarchical arm, seed s) - ADE6(flat arm, seed s)], paired per window, point value = ratio of sums (a window with a non-finite value drops out of both sides). Negative = hierarchy better. D = mean of the d_s over S*.

## Statistics
* R7 Interval A (decides): two-level bootstrap, B 2,000, numpy `default_rng(0)`. Per draw: choose |S*| seeds with replacement; for each chosen slot draw an independent set of episodes with replacement (multinomial counts over the 141 episodes, the same unit as `taniteval.ci`); the slot value is (sum of window differences over drawn episodes) / (count of finite class windows over drawn episodes); D* = mean over slots. 95 % percentile interval; "excludes 0" is decided on unrounded bounds.
* R8 Test B: exact sign-flip over the d_s (all 2^|S*| sign assignments, statistic = mean, two-sided, p = share with |D_flip| >= |D_obs| - 1e-12). With six seeds the smallest p is 2/64 = 0.03125. Reported; the card's label uses "all six same sign", which is the p = 0.03125 event.
* R9 Interval C (reported, decides nothing): mean +/- t(0.975, n-1) x sd / sqrt(n); t table hard-coded for n-1 = 1..10.
* R10 Label per class: HIER = all d_s < 0 and interval A hi < 0; FLAT = all d_s > 0 and interval A lo > 0; else OPEN. Four outcomes exactly as the card (Stage 2 is the primary protocol: DAG vs FLATDAG): HIER-DOMINATES = critical HIER and all-windows HIER; HIER-ON-CRITICAL = critical HIER and all-windows not HIER (bulk difference printed as the named cost); NOT-ESTABLISHED = critical OPEN; FLAT-AHEAD = critical FLAT. Stage 1 gets the same four labels as secondary.
* R11 Noise floor, beside every difference: per arm type (HIER, FLAT, DAG, FLATDAG), for each of the C(|S*|,2) = 15 seed pairs (a < b): difference of the class-mean ADE6 of the SAME arm type between two seeds on the same windows; report median |difference| and how many pairs `taniteval.ci.paired_episode_cluster_bootstrap` (B 2,000, seed 0) calls separated. Per class (critical, bulk, all).
* R12 Control r4: 20 draws (draw k uses `default_rng(1000 + k)`); in each draw every seed's arm labels are swapped with probability 0.5 independently (a swapped seed has d_s -> -d_s exactly, the pair being paired per window); the Stage 2 critical-class label is recomputed with R7 and R10. PASS = OPEN in at least 18 of 20. The count and every draw's label are printed.
* R13 Families on ALL windows, both protocols, same statistics (R6 to R10, "HIER" = hierarchy lower): LONGITUDINAL speed MAE (m/s), along-track MAE (m); LATERAL cross-track MAE (m), heading MAE (deg), curvature MAE (1/m), yaw-rate MAE (deg/s) (components of HIERWHERE `comps`, which copies four_families' definitions and masks); TACTICAL = decision error rates of the arm's trajectory mode against the logged mode (longitudinal 4-way, lateral 3-way, joint 12-way; error rate, lower better) plus the tactical-band ADE of R4. Windows with a non-finite component drop out of that row (n windows printed).
* R14 NAMED GAPS, printed in the verdict and never as a pass: (a) headway and time gap (LONGITUDINAL distance keeping) need a per-window lead block that the T1-kin dumps do not carry and the pod does not hold (dump_lead_join inputs are dev-box side): GAP; (b) tactical goal-setting (stop-goal decision) needs a goal label file per arm: GAP; (c) STRATEGIC: PAUSED (PI item 25), never a pass, never omitted.

## Control r1 (harness) and r2 (gate)
* R15 r1: `hierrep_read.py r1 --dump <dir> --ref r1_reference.json`: the pod dump of `stopbal_BAL-NULL_s0` read with the R4 ADE6 over all windows must equal `ade6_all_windows_m` of the reference within 0.005 m (and n windows equal). `r1_reference.json` is shipped by the lead, keys `ade6_all_windows_m`, `n_windows`. Absent file = PENDING, recorded as PENDING, never as a pass. FAIL = the chain stops before any arm.
* R16 r2 gate: every one of the 24 arms' selfchecks must have `declared_vs_built == PASS`, `live.pass`, `live.control_prior_grad_sum == 0.0` (written to the token). The deliberate-regression arm (`r2_regress_gate.py`): the trainer's own `main` is run with the HIER argv (`--o-interface` absent = full) after replacing its `make_config` by a wrapper that sets `o_interface="cut"` in the built config, so the model is built with the cut while the argv declares full. It must exit non-zero with the trainer's `ZZDVB-REFUSEDZZ` refusal mentioning `o_interface`. What is built: a monkeypatch of one function in the imported trainer module, no edit to the trainer. NOT TESTED on this box (no GPU, no cache); it runs for the first time on the pod, and a pass there proves only that the declared-vs-built check sees this mismatch. Named gap if the trainer's refusal comes from another check than G-DVB (the log text is kept).
* R17 Token and argv identity: the gated argv and the training argv are compared after normalisation (`--selfcheck-only` removed, the value after `--out` replaced by `<OUT>`); sha256 of the normalised tokens joined by newline. The token stores it with the commit, the trainer's selfcheck `argv_sha`, `selfcheck.json` sha256, the train sha256, the excluded sha256 and the data hashes. After training, `<OUT>/argv.json` is normalised and compared again.

## Exit codes and outputs
`hierrep_read.py read`: 0 read written and controls r3, r4, r5-structure pass; 2 a control failed (files are still written, headed READ NOT VALID); 3 input error. Outputs `RESULT_HIERREP.json`, `VERDICT_HIERREP.md` (tier stamp, evidence class, estimator, n windows / episodes / seeds in every table).
