# READSIDE_WMPOOL: what must build z1 from cells for a P-ATT arm (listed, NOT implemented; each change is a few lines but needs the cell frames of the eval clips)
A P-ATT model RAISES on `wm.z1_from_mean` (by design: a token mean handed to it would silently run the mean pool), so an unchanged reader fails loudly rather than reading a wrong z1. The readers pass `fr["zmean"][ci]` [T, 256] (frames npz from `ladder_read/lr_lib.py build_eval_frames`).
1. `theory/ladder_read/lr_lib.py`
   * `build_eval_frames` (l. 180-196): also store `zcell` [sum T, 10, 256] = `zcells.zcell_of(model, d["feats"])` (same adapter + pos, `adapter_sha` already stored), via `np.savez(..., zcell=...)`.
   * `load_eval_frames` (l. 199-204): split `zcell` like `zmean` when the key exists.
   * `encode_clip` (l. 232-239): `z1 = wm.z1_from_cells(x[None])` when `getattr(wm, "pool_q", None) is not None` (x = the clip's cells [T, 10, 256]), else `wm.z1_from_mean`. Callers at l. 352, 606, 641, 682 pass `fr["cell" if pattn else "zmean"][ci]`.
2. `theory/ladder_plantest/lp_lib.py` `clip_z1` (l. 276-281): the same dispatch, `wm.z1_from_cells(torch.as_tensor(cell)[None])[0]`. `rollout_h` (l. 50) works on latents, not on tokens, so it is unchanged. Goal latents come from `clip_z1`, so they follow.
3. `theory/egowm/read/lr_speed.py` (IA-0 reader wrapper, `_encode_clip(model, zmean, act, contrast)` keyed by `id(fr['zmean'][ci])`): the speed registry is EGOWM's (`E-*` arms only); P-ATT has no speed channel, so the IA-0 read for P-ATT calls `lr_lib` directly and needs only item 1. `egowm/read/controls_read.py` plants `zmean` and is not used for P-ATT.
4. The frames file for P-ATT readers must be built with the SAME frozen adapter as the training cell cache; `adapter_sha` is the key (the manifest's `adapter_state_sha256` has the same formula).
5. Attention-weight entropy per level (the card's "beside, no bar" item): `wm.pool_weights(cells)` [B, F, 10] gives the weights; entropy = `-(w*log w).sum(-1)`, uniform = ln 10 = 2.3026.
Size: ~35 lines across items 1-2, so under the 60-line bar, but not written because no cell frames exist yet and the readers are another stream's files.

## Implemented (Master Mind, 2026-11-11 ~07:15, before any P-ATT checkpoint exists)
Items 1, 2 and 5 are in the code; item 3 needs nothing (the IA-0 read for P-ATT calls `lr_lib` directly); item 4 is enforced by the code.
* `ladder_read/lr_lib.py`: `is_pattn(model)` (the `pool_q` query is built); `zcell_of` (the 2 x 5 cells of the frozen adapter's tokens, `WMAux.cells_of_adapt`); `z_in(model, fr, ci)` picks the input by the MODEL, never by the file (cells for P-ATT, else the token mean) and raises on a P-ATT model whose frames carry no cells; `build_eval_cells` writes `cells_s<seed>.npz` (clips, T, zcell, adapter hash) beside the frames file, written whole and then renamed; `load_eval_frames(path, cells=)` refuses a cells file whose clips, T or adapter hash differ from the frames file; `encode_clip` reads cells through `z1_from_cells` on a P-ATT model and refuses a token mean; the four callers pass `z_in(...)`; `pool_stats` (item 5): entropy of the weights over every eval frame (uniform = ln 10), its 5th percentile, the mean largest weight, the mean weight per cell, the query norm. The pool sits only at the level-1 input, so there is ONE weight set for the whole stack, not one per level (the card's "per level").
* `ladder_read/run_ladder_read.py`: a P-ATT arm builds or loads `cells_s<seed>.npz`; its result carries `pool_beside`. Earlier arms take exactly the old path.
* `ladder_plantest/lp_lib.py`: `clip_z1` dispatches like `encode_clip`; `prepare_arm` loads `cells_s<seed>.npz` for a P-ATT arm (built by the ladder read first, so the planner refuses loudly if it is missing).
* Evidence: `controls_readside.py` -> `CONTROLS_READSIDE.json` (pass, CPU, 4.2 s; two random-weight models from the patch commit `abc01481`, two REAL eval clips): cells of the reader = the box-2 builder's (`zcells.zcell_of`) 0.0; reader z1 = the TRAINING path `wm.z1(tokens)` 2.1e-7 with a non-zero query (entropy 2.007 < ln 10); states at every level and `lp_lib.clip_z1` 2.1e-7; a MEAN model reads bit-identically to the unedited files (with and without cells in the frames dict, all four contrasts); the four refusals fire; zero query entropy = ln 10 within fp32 (1.9e-8). Three deliberate-regression arms go RED (`is_pattn` forced off; input chosen by the file; 2 x 2 blocks over the wrong axes). The first run failed only its own entropy tolerance (1e-9 against fp32 weights, 1.9e-8 measured); it is 1e-6 now, stated in the script. `test_ladder_read.py` on the edited reader: 13 passed.
