# RESULTS: H-CRAWL-01 / -02 / -03 (zero training, dev-box CPU)

Every number below is **MEASURED (ours)**; artifact `CRAWL_DIAG.json` (parts in `raw/part_01.json`, `part_02.json`, `part_03.json`), produced by `crawl_diag.py`. Cards: `PREREG_FROZEN.md` (sha in `FROZEN_SHA.txt`). Choices fixed before any result: `READINGS.md` (sha in `READINGS_SHA.txt`). Nothing in either was changed after data.
**Tier.** H-CRAWL-01 gaps: **T1-kin** (the car's own executed state, logged camera; a self-action OPEN loop, never "closed loop"). H-CRAWL-02: first-tick inference at tick 0 = **T0-class** (teacher-forced, one `forward_infer` call, no rollout), never "driving performance"; the counterfactual inputs are measurement tools and are not deployed.
**Estimator.** `taniteval.ci` episode-cluster bootstrap (paired for differences), B = 2000, seed 0, over the episodes of each subset. It answers **only** "would another draw of episodes say this?". It is blind to training variance (two runs = two training seeds of one recipe; `H-ESTIM-SEED-1`) and no inference seed exists (the planner is deterministic). Sign: negative gap = slower than the human. Gap = mean over ticks {1, 2} of (v_own - v_GT), mlaunch reading R1, on the 327 GT-launch windows / 49 episodes.
**Runs.** DAG-OACC s0 = ckpt sha `67265ec1...`, REP s0 = `b03fd6ef...` (recomputed, equal to the `done_*.txt` records).

## 3. H-CRAWL-02 numbers

**Where speed enters (file:line, tool tree `dagt1_tree_b43c7a9a`).** `V8FMini.forward_infer` `stack/tanitad/models/v8f_mini.py:773` -> `_forward` :726 -> `run_s` :672, `run_t` :683, `run_o` :698 (which calls `prior(p10f[NOW], base)` :710). The batch is built by `stack/scripts/v8f_t1_eval.py` `build_item` :237 + `D.collate`, keys `MODEL_KEYS` :62, ages (0, 0) at tick 0 (`ages_for` :136). At tick 0 the model reads **only the NOW row** of `p10f` (v, a, kappa and products), `base` (kd_x extrapolation of v0, a0, kappa0) and the `limit` 4 s max-speed bucket; older `p10f` rows are not read (scrambling them changes the plan by exactly 0.0). So "speed history" reaches the planner as the one-frame backward difference `a`, the v-dependence of kappa, `base` and the bucket. Plan = upsampled P10 prior + a learned residual.
**Counterfactual (closest faithful version).** The native-track speed column and the cache speed are changed (v' = max(v + delta, 0)); every derived input is rebuilt with the tool's own functions; positions, yaw and camera are untouched. * Small subsets: stopped launch 61 windows / 15 episodes, GT-stay 32 / 10, stopped-start S_v 61 / 15. One table specification (edges fixed in READINGS); the median-vs-mean choice changes magnitudes but not the per-run committed outcome.
* The H-CRAWL-02 counterfactual changes the speed channel only (odometry untouched); T0-class, one forward call, no replanning.
