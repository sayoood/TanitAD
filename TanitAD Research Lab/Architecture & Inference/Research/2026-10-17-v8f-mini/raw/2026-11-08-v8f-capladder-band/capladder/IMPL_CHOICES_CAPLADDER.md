## 5. The probe
* **Deciding probe, per outer fold k:** features of all rows of the set standardised with the mean and the population standard deviation (+ 1e-8) of the **fit-fold rows** (the rows of the set whose fold is not k). Kernel K^k = X~ X~^T (linear kernel on the standardised features), accumulated over feature chunks of 16,384 in float32, matmul TF32 off (`allow_tf32` False), on the GPU if the rule above allows, else the CPU.
* **Dual ridge with an intercept.** For a fit set F and score set S: the kernel is centred on F (K~_FF = K_FF - r 1^T - 1 r^T + m, K~_SF = K_SF - rowmean(K_SF) 1^T - 1 r^T + m, r the column means of K_FF over F, m their mean), y is centred by its F mean, lambda_c = c * tr(K~_FF) / n_F with c in {1e-4, 1e-3, 1e-2, 1e-1, 1, 10, 100}; prediction = K~_SF alpha + mean(y_F). One float64 `eigh` of K~_FF gives all seven lambdas.
* **Selecting c:** inner 5-fold episode CV on the fit fold (inner fold `sha256(episode|inner)[:8] % 5`; empty inner folds skipped), pooled inner SSE, the c with the smallest SSE (first on ties). The inner CV uses the outer fold's standardised features and the kernel centred on each inner fit set (the standardisation uses no labels). The outer model is refitted on the whole fit fold at the selected c and scores the scoring fold.
* **NMSE** = sum of squared errors over all rows of the set (each row scored by the probe of its own scoring fold) / sum of (y - mean of its fit fold's real labels)^2. For a reference draw the denominator is the same constant (the real labels' fit-fold mean), so draws and real are on one scale.
* **Reference:** R = 199 draws, s = 1..199: `rng = default_rng(s)`; for k = 0..4 in order, `perm_labels(y[F_k], episode[F_k], rng)`; the whole probe (c selection included) refits on the deranged fit-fold labels and scores the true labels of the scoring fold. The same deranged labels feed every rung (so a paired difference recomputes both terms on the same labels). Percentiles are `numpy.percentile` (linear). Reference points are stored per draw per rung; per-episode SSE for every draw is stored, so a draw can be scored "as if real".
* **READABLE(r)** = bootstrap 97.5th percentile of NMSE < 1 AND point < 2.5th percentile of the 199 reference points. **LOSS(r -> r')** = 2.5th percentile of the paired bootstrap Delta > 0 AND Delta point > 97.5th percentile of the 199 reference Deltas. Two-part, both parts as the card writes them.
* **Beside targets (real labels, point + episode-cluster bootstrap interval, no reference, no bar):** `lead_closing`, `ttc` (set B), `log(max(lead_gap, 0.1 m))` (set A), `lead_gap` <= 30 m (set C): for B and C the kernel is the sub-block of A's standardised kernel (standardisation by the A fit fold; the fit rows are the set's rows in the fit fold). `lead_present` (set D, its own Gram, standardised by D's fit fold; regression on {0, 1}, class = prediction >= 0.5; score balanced accuracy - 0.5). These are computed for R0, R1, R2, R2m, R3 and R4 (both seeds) only.
* **Beside MLP:** the IMAG1B bank (hidden 64, 3 probe seeds, `MLPBank`, early stop on the fit-fold rows with `sha256(episode|inner)[:8] % 5 == 0`) on a 256-component PCA of each rung fitted on the fit fold (the components come from the same `eigh` of the standardised, centred kernel: fit scores = U sqrt(s), other rows K~_SF U / sqrt(s); all components divided by one scalar so the mean component variance is 1), on `lead_gap` over set A, real labels, point + interval, no reference. Rungs: R0, R1, R2, R2m, R3, R4 (both seeds).

## 7. Controls
1. **Calibration:** 20 extra draws, seeds 1001..1020, same derangement and refit, scored against the reference of each row **as if real** (point from the draw's own per-episode SSE, bootstrap interval from the same weights, the draw's value compared with the 199 reference points). Rows counted: READABLE rows = every rung of set A with a reference; LOSS rows = every pair (R0->R1, R1->R2, R2->R3 s0/s1, R2->R4 s0/s1, R3->R4 s0/s1 beside, R2->L1, L1->L2, L2->L3 s0/s1 beside, and the corresponding beside rungs). **At most 5 % separated, per row kind** (READABLE, LOSS), over all rows and, printed, per kind and seed.
2. **Dimension:** a Gaussian matrix of the same n x d, `seed 0` (per-chunk `torch.Generator().manual_seed(1_000_003 * 0 + chunk_index)`), for every distinct d in {655,360; 163,840; 40,960; 3,072; 1,024; 384; 128} on the n = 2,489 rows of set A, run through the identical pipeline with its own 199-draw reference; it must NOT be READABLE. One Gaussian serves every rung of that d.
3. **Planted (synthetic, `test_capladder_controls.py` with R = 39, 6 calibration draws, B 500):** (a) a gap channel planted into R2 at SNR 1 is READABLE; (b) a +/- checkerboard over the 2 x 2 cells, which cancels under 2 x 2 averaging, gives LOSS(R0 -> R1) and no READABLE at R1; (c) one channel copied to every rung (R0 .. R4, identical noise width) gives no LOSS anywhere. Added deliberate-regression arms: a non-cancelling constant pattern in (b) gives NO loss; a Gaussian replaced by the planted matrix makes control 2 FAIL; a reference shifted down by 0.5 makes control 1 FAIL; a pooled field cut by a one-cell shift fails control 4. Also a unit check that the dual ridge equals the primal ridge on standardised features at a fixed lambda, intercept included.
4. **R0 identity:** section 4.
* **Banner:** VALID iff controls 1, 2 and 3 pass (control 3 = `TEST_CAPLADDER.done` rc 0 with every test passing). INVALID -> only the control rows are written, with the cheapest next lever named from them. Control 4 decides only R0.

## 8. Outcomes (readings fixed here)
Seeds: a model-rung row is READABLE / LOSS only if the label holds at **both** seeds; one yes and one no is SEEDS-DISAGREE and decides nothing.
* **O-ENC:** not READABLE at R0 (R0 admissible), or not READABLE at R1 when R0 is NOT RUN / NOT COMPARABLE.
* **O-POOL8:** READABLE(R0) and LOSS(R0 -> R1). **O-POOL4:** READABLE(R1) and LOSS(R1 -> R2).
* **O-NET:** READABLE(R2) and, at each of the two seeds, LOSS(R2 -> R3) or LOSS(R2 -> R4) (step-wise booleans printed). R3 -> R4 is not used (section 3).
* **O-DIFFUSE:** READABLE(R2), not READABLE(R4) at both seeds, and at each seed none of LOSS(R2 -> R3), LOSS(R2 -> R4), LOSS(R2 -> L1), LOSS(L1 -> L2), LOSS(L2 -> L3).
* **O-NONE:** READABLE(R4) at both seeds.
* Several can hold; they are ranked by the separated Delta NMSE of their step (O-NET: the smaller of the two seeds' largest separated step), O-ENC listed first, unranked.
