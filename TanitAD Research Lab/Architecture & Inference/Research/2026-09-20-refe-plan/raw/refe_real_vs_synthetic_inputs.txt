  loaded 8/8 frames

  pairwise L2 between REAL frames      mean    7.40  min   4.85  max  10.18
  pairwise L2 between SYNTHETIC noise  mean  294.29
  => synthetic inputs sit ~39.8x further apart than real consecutive frames

  pairwise max|target diff|            mean    0.96 m

MECHANISM: the synthetic arm gets 8 INDEPENDENT noise patterns -- effectively a perfect
per-index lookup key, so memorising 8 targets is trivial. The real arm gets 8 frames taken
0.1 s apart from the SAME scenario, i.e. near-identical inputs that must map to targets
differing by ~1.0 m. That is a genuinely harder function to fit, and it is a property of
HOW THE 8 TUPLES WERE CHOSEN (the first 8 rows of the bank), not of real imagery as such.

=> An overfit control on 8 CONSECUTIVE frames is a weak test. A better one samples 8 tuples
   from DIFFERENT scenarios. Noted for the pod: do not read the real-vs-synthetic gap as a
   statement about image difficulty until that is redone.

FIX APPLIED: train.py --spread

  default (first 8 rows)   pairwise L2  7.40   1 scenario, frames 0.1 s apart
  --spread (every 40th)    pairwise L2 57.60   3 scenarios   => 7.8x more separated
  synthetic noise          pairwise L2 294.29

CONSEQUENCE FOR THE COMPARISON THAT WAS RUNNING:
  the ViT-S batch-8 synthetic-vs-real isolation was intended to move ONLY the images, and it did --
  but BOTH arms drew the SAME 8 consecutive frames of one scenario, so the real arm faced a much
  harder function (near-identical inputs, ~1 m apart targets) than the synthetic arm (independent
  noise = a perfect per-index key). The arms are therefore NOT a clean test of "are real images
  harder"; they are a test of "is memorising 8 near-duplicate frames harder than memorising 8
  independent noise patterns", whose answer was never in doubt.

  => Any real-vs-synthetic gap must be re-measured with --spread before it is quoted at all.
  => The SYNTHETIC path's value is unchanged: it validates loop MECHANICS. It was never meant to
     be a difficulty baseline, and using it as one was my error, not the harness's.

WHAT STILL STANDS FROM THE ORIGINAL RUNS:
  * the loop learns on real camera frames (1.0781 -> 0.1791, PASS) -- a pass is a pass regardless
    of how the 8 tuples were drawn;
  * the deliberate-regression arm froze at 1.2460, so the control is discriminating;
  * WTA winner diversity is bounded by batch size (arithmetic, unaffected by sampling).
