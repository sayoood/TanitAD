## 1. Diagnosis (the cause of the C-R0 failure)

Evidence class MEASURED unless stated; artifacts in `raw/` beside this file.

- **Root cause: the roll thread count.** The banked navtest rollouts (2026-10-05) were rolled with `OMP_NUM_THREADS=2 MKL_NUM_THREADS=2`, `--threads 2` (`PK/raw/2026-10-05-teacher-navtest/full_s{0..3}of4.log` header, "torch threads 2"). The TF-N2 chain rolled with 1 thread: `tfn2_nt_chain.py:329` passes `"--threads", "1"` to `run_p4.py`, and `p4_R0_s0.log` header reads `OMP_NUM_THREADS=1`. Torch CPU reductions change summation order with the thread count, and the 10 Hz closed loop amplifies the last-bit differences.
- **Inputs are not the cause.** Field by field on all 240 tokens, fresh (1 thread) against bank: `goal`, `v0`, `corrected_route_n`, `raw_route_n`, `history_clamped`, `buffer_s`, `dt` are identical on 240/240 (max `goal` difference 0.0). The fresh rows carry the same fields as the bank, plus `tts`, `knobs`, `arm`. Environment (same interpreter `driverl-eval`, python 3.11.13, torch 2.7.1+cu128, numpy 1.26.4, because `run_p4.py` fixes `PY_D`), `REFE_SIM_HZ` 10, code and export are the same.
- **Test.** The identical roller and tokens re-rolled with `--threads 2` (`run_p4.py --threads 2`):
  - 30 tokens (the 15 worst and 15 clean): 0 over 1e-6, max |d| **0.0**, 30/30 bit-exact.
  - **All 240 subset tokens: 0 over 1e-6, max |d| 0.0, 240/240 bit-exact** against the bank (`raw/threads2_identity.json`, `raw/rows_s*of2.jsonl`). The 1-thread roll differs on 111/240 (max 0.0183 m, heavy-tailed: median per-token max about 1e-6, one token at 0.0183 m).
- **Why navtrain matched at 0.0:** the navtrain bank (TF-2b) was rolled with `--threads 1` (`reroll/tfn2_reroll_chain.py:133`), so a 1-thread re-roll matched it. The navtrain match is evidence that a re-roll is exact **at the bank's own thread count**, not that the count is irrelevant.
- **Prior sign in the repo (MEASURED):** the bank's own C3 check, a 4-thread re-roll of 47 tokens against banked targets, read median 8.1e-7, p90 7.5e-6 and **max 0.0262 m** (`c3_heldout_10hz.json`). The same drift was visible on 2026-10-05.
- **Not a bug fix.** Nothing was reverted. The code is unchanged; only the thread argument differs. Route (a) applies: identity is restored.
