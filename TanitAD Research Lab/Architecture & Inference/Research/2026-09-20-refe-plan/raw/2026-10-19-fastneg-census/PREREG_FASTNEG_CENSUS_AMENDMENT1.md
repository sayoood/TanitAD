## A1.2 Speeds, base pick, strata (parent section 3)
* `v = (|p_1| + sum_{k=1..19} |p_{k+1} - p_k|) / 4.0 s`, with `p_k` the (x, y) of pose k and the ego origin (0, 0) at t0 (pose 1 is at t = 0.2 s). `r = v_p / v_b` is invariant to dt; **dt enters only the standstill threshold** (v_b < 0.5 m/s, strict, equivalently a base-pick path length < 2.0 m over the horizon). dt = 0.2 s is MEASURED in the repo source (model.py, SRC_DT) and not re-derived from data; a control reports first-segment length over the median later-segment length (a pose 1 at t0 would read 0).

## A1.3 Labels, unsafe, AUC (parent section 4)
* Row label convention (= HEADROW-PROBE section 3.1): NC `labels6[...,0]` in {0, 0.5, 1}, soft BCE target; DAC `labels6[...,1]` in {0, 1}; all 64 proposals valid for both rows.
* **Per-row classes for pairs:** unsafe_ρ = (label_ρ == 0), safe_ρ = (label_ρ == 1). An NC = 0.5 entry (and any value outside {0, 0.5, 1}) is neither and is excluded from pairs (counted in (a)). **(a)'s "unsafe" for the composite share = (NC == 0) or (DAC == 0), as the parent writes.** Descriptive sensitivity with no authority: unsafe_ρ := (label_ρ < 1).
* **Within-token AUC** = sum over sets of concordant (u, v) pairs (u unsafe, v safe, score_v > score_u, ties 0.5) divided by the number of such pairs, with **both members of a pair in the stratum's member set**: S = the proposals of S sets; Qk = that stratum; **pooled Q1-Q3 = the union Q1 ∪ Q2 ∪ Q3 (cross-quartile pairs inside the union included)**; F = Q4. Score = the row's logit (monotone in the probability). The unit of the bootstrap is the LOG: per-log numerators and denominators, `epr1.boot_draws(117, 10000, 20260927)`, percentile 2.5 / 97.5, every difference computed on the SAME draws as a difference of two ratio-of-sums. Descriptive sensitivity with no authority: pairs with the unsafe member in the stratum and the safe member anywhere in the set.
* (a) per stratum: rows, NC = 0 / NC = 0.5 / DAC = 0 / (NC = 0 or DAC = 0) counts, the unsafe share (rows with NC = 0 or DAC = 0 over rows, a ratio over logs), the share of ALL unsafe rows, and the admitted pairs per row. Descriptive; no rule.
* (b)(i) = the stored P2 logits columns 0 and 1 (in-sample for P2). (b)(ii) = HEADROW-PROBE's saved `oof_{nc,dac}_{L,M}_s{0,1}` tables, read only from its own `oof_proposals_f10.npz`; matched to the bank by the set key; mismatch of the key list STOPS.

## A1.4 The L-arm refit (parent section 4(c)); recipe = HEADROW-PROBE section 3.2
* z = z_stored + feat . (w - p2_w) + (b - p2_b); (w, b) initialised to P2's rows 0 (NC) and 1 (DAC) of `score_head`; features fp16 -> fp32 and DETACHED; Adam(lr 1e-3, betas (0.9, 0.999), eps 1e-8, weight_decay 1e-4, coupled L2 on w and b); 20 epochs; minibatches of 256 sets; each epoch's order `randperm` from `torch.Generator().manual_seed(seed * 1_000_003 + len(train_idx))` over the ASCENDING training set index (train = sets of logs with fold != k, fold = rank mod 5); deterministic algorithms, 8 threads; loss = BCE_with_logits(z, y) averaged over the INCLUDED entries of the minibatch. The NC and DAC rows are fitted in ONE module with disjoint parameters and a summed loss: each parameter's gradient depends only on its own row's term and Adam is element-wise, so this equals two separate fits with the same batches up to floating-point summation order. Seeds {0, 1}.
* **F-subsample:** a training entry in Q4 is included iff `u < frac`, with `u` drawn once per (set, proposal) from `numpy.random.default_rng(20261019 + 7 * seed)` (so 25 % is nested in 50 % is nested in 100 %); S, Q1, Q2, Q3 entries are always included. The batch order does not depend on `frac` (it depends on `len(train_idx)`, which is unchanged), so the three sizes see the same batches and differ only in the loss mask. OOF evaluation always uses ALL entries of the held-out fold.
* **The rule's input** (parent section 5, "the L arm at 100 %") is OUR 100 % refit. HEADROW-PROBE's L OOF (b)(ii) is run through the same rule as a robustness read; if the two classes differ the outcome is reported with BOTH and ours governs. Control C-REPRO: max |our 100 % L logit - the probe's L logit| over all OOF entries is reported (the recipe is the probe's, so it should be ~0 up to summation order).

## A1.5 The powered null (c0)
For replicate r = 1..5 and each head-fit seed s in {0, 1}: two 100 % L refits A and B that differ ONLY in the batch-order generator seed (`seed * 1_000_003 + len(train_idx) + 7919 * (2r - 1)` for A and `+ 7919 * (2r)` for B; the registered fits use +0). A replicate FIRES for a row iff the paired CI of `AUC_F(A) - AUC_F(B)` has lower bound > +0.01 on BOTH seeds (the COVERAGE rule's slope test). **The census is VOID iff, for either row, the null fires on >= 2 of the 5 replicates.** Every replicate's CI is reported.

## A1.6 Outcome mapping when the two rows disagree (parent section 6 is silent)
Row classes: COVERAGE, FEATURE, NO DEFICIT, INCONCLUSIVE (a row is classified only if both seeds agree; a row whose DEFICIT is not found on both seeds and whose NO DEFICIT is not found on both seeds is INCONCLUSIVE). Precedence: (1) COVERAGE on NC or DAC; (2) FEATURE on both; (3) NO DEFICIT on both; (4) everything else, including FEATURE + NO DEFICIT, FEATURE + INCONCLUSIVE and NO DEFICIT + INCONCLUSIVE, is INCONCLUSIVE and takes the re-run at f = 25 % with its cost named. VOID by the null overrides all four.
