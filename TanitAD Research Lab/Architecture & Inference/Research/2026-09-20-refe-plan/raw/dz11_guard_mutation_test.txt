  have surfaced the moment the arrange fired -- overnight -- rather than now.

  still checked by DB count AND size, which is what stops a MINI directory being scored as val14.

TEST DESIGN NOTES, kept from the first run and extended
* Case 3 was initially UNREACHABLE -- the size guard fired first, so the branch it was meant to
  exercise never ran and the test would have been green without proving anything. Thresholds are
  env-overridable ONLY to reach it, and any override prints
  "*** THIS IS A TEST MODE. Any score produced under it is INADMISSIBLE."
* Cases 6 and 7 are the discriminating controls. Without them, a guard that refuses EVERYTHING
  passes 1-5 and is green forever in the wrong direction. ⭐ Arm 6 is also the only arm that would
  have caught the coupling being fixed here: it is exactly the configuration the headline run will
  be launched in tonight.
* A PASS control reports rc 2, not 0 -- the preflight is cleared and the REAL eval then fails on a
  fixture of empty files. The control is the HEADLINE_RUN marker, never the exit code.
