# S1c auto-reader — report (Master Mind, 2026-10-16)

The Sonnet agent built this package. Its harness refused a `REPORT.md`, so this file records the hand-back plus the Master Mind's re-verification.

## What it is
`s1c_autoread.py` polls `Sayood/tanitad-refe-s1aux` for the complete S1c arm `arms/H1u10k-s0/` (13 files), fetches and verifies it, then reads it exactly as `eval/PREREG_S1C.md` and `eval/PREREG_AUXVETO.md` A1 commit:
1. C1 / run-check / evidence;
2. a C3 forward, with S1's H1-s0 as the comparator in the SAME call;
3. K2 + the budget contrast;
4. the natural population (`nat_p1.py`);
5. V-S1C (`s1c_veto.py`);
6. the descriptive selection.

Outputs:
- `out/RESULT.md` + `RESULT.json`;
- a marker, either `out/S1CREAD_DONE` (a recorded O1–O4 row) or `out/S1CREAD_FAILED <reason>`, INVALID included.

The launcher is `launch_s1c_autoread.ps1`. It is resumable, polls ≤ 48 h, and must run from a checkout of the landed package.

## Device policy
`auto`: the GPU under the shared `devbox_gpu.lock`, else CPU. The device is accepted only if the comparator reproduces S1's banked reads on it:
- CPU within 1e-9;
- CUDA within 1e-4. This tolerance is UNVERIFIED on a real GPU (the lock was held by another session's job). A miss re-runs on CPU.

## Interpretation choices (all in `QUESTIONS.md`, pinned by tests, written before any S1c number existed)
- **INVALID is extended** beyond the prereg's two clauses. It also fires when the arm's evidence contradicts its label (token profile, argv, `sft.jsonl` facts). This can only make a read stricter.
- STRATEGIC is printed PAUSED (PI ruling 2026-09-19, item 25).
- Any S1c-vs-S1 difference is single-seed: "separated, single seed, not yet a lever claim" (H-ESTIM-SEED-1).
