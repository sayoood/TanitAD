## The arm and why

* **K2SG** is `stack/ops/runs.d/r9e2_K2M1N20.argv.json` (the trained K2 of the E2 read: `--w-map-hires 25`, banded head, `--r9-hist-supervise-geom`, `--r9-plan-map-channels`, no share controller) with one change: **`--map-hires-trunk-grad-scale 0.0`**.
  * The rest is identical: 6,000 steps, seed 0, profile `refcv9-e2`, and its own run dir.
* **The lever.** It comes from hold `hold_r9_maptrunk_gs`: `stack/tanitad/train/map_trunk_gs.py`, plus `map_head_hires.py` `_gs`. The op multiplies the map loss's gradient by S, and only at the inputs the banded map head takes from shared features:
  * the trunk's stride-8 map (the near lift);
  * the shared lift/encoder output `feats`, which the planner pool also reads;
  * with M3, the input of the map's own encoder.
  * The map head's own parameters keep their full gradient. The planner reads the **unscaled** `feats`.
  * At S = 0 the map term reaches no shared parameter. The shared lift/encoder still train, from every other term.
  * The op adds no parameters: `state_dict` is unchanged, and the default 1.0 inserts no op at all.
* **Why this arm.** In the E2 read, K2 lost LATERAL against K0 (clause (d)) at seeds 0 and 1.
  * Six zero-training reads did not remove the gap (GOALS `H-R9-E2-WISE`).
  * Under K2's fixed weight, the map term held **0.388 / 0.809 / 0.770** of the trunk gradient at steps 1,000 / 3,000 / 5,000. This is MEASURED in `e2/read_K2M1N20/knockouts/diag_dose/` (RETRACTION R-E2-DOSE-1).
  * K2DC and K2DC02 **reduce** that share with a controller. K2SG **removes** it. If map gradient reaching the shared trunk causes the lateral deficit, K2SG is the arm where the deficit must vanish.
  * PREREG_K2DC02 §4 item 2 names this lever: "a stop-gradient from the map head into the trunk".

## 2. Validity: was the gradient actually stopped?

S = 0 is an analytic identity, so the test is exact, not a band. The arm counts as a test of the stop-gradient only if the trainer's own `gs_*` telemetry shows both of the following:
* the `map_hires` term's **trunk** share reads **exactly 0.0** on every telemetry row at step ≥ 1;
* the `tac_v6` row reads **non-zero**, as the control that the probe works.

The telemetry is K2M1N20's `--grad-share-every`, `--grad-share-terms tac_v6,map_hires` and `--grad-share-at` set, unchanged.

Otherwise the read is **OP-VOID**:
* All E2 numbers are still reported.
* The arm is not evidence about the stop-gradient.
* The next step is a reachability fix, traced flag → loss as the CLAUDE.md "built, tested, and unreachable" rule requires.
