aMulti-hierarchy and contrastive critics811

Every level is a dot-product critic between a unit-norm state readout and cached node embeddings, trained with level-wide negatives: a sibling-only softmax leaves a per-parent offset free and mis-orders nodes across parents.

p̃ℓ(v | s) = softmaxv′∈Vℓ( τℓ⟨sℓ, av′⟩ + βℓ log q̄ℓ(v′) ),  τ = eθ, init 1/0.07, clamp 100
  • Soft targets: y(a) ∝ exp(−dtw(y*, ŷa)² / 2σ²), σ = 0.5 m, summed up to ancestors ⇒ β = 0 by default
  • Consistency: Σℓ KL( sg[p̂cascadeℓ] ‖ p̃ℓ ) ties critics to the beam
  • Goal loss: 22 goals, BCE (positive weight ≤ 50) + goal point at 2 / 4 / 6 s
  • Matryoshka readouts at 128 / 256 / 512: a free option, expected to save nothing
  • Masked vs unmasked InfoNCE vs soft-target softmax is an ablation (H-HC4), not assumed
L = ΣℓλℓLvocℓ + λcLcons + λgLgoal + λkLcost + λrLref + λiLimg + λaLaud + λfLcfg
a* = argmina∈K Σk wk ĉk(s, a) − λ log p̂(a | s),  w fixed a priori, λ fit on held-out train episodes

iAdmissibility rulesbinding

  • 1The goal / route path never reads the situation or country posterior; there is no situation-classifier head; rule memory never feeds the goal token.
  • 2Vision-only gate: G-V reads frames only; G-E (ego) is an ablation pending a ruling; G-T is not provided.
  • 3Audio-off primary numbers; audio-on is a paired arm; the audio-only label probe must sit at chance.
  • 4Labels may use ego future and agents; inference sees frames, v, alon, yaw rate and the stamped oracle nav / route, each with zeroed and shuffled controls.
  • 5A parent restricts its children but is never a feature of the child readout; explanations never feed control.
  • 6The country label (upstream metadata) is never an inference input except in the supplied GNSS arm; both arms reported.
  • 7Four metric families, per family, never pooled; paired episode-cluster bootstrap on the full-set mean.
