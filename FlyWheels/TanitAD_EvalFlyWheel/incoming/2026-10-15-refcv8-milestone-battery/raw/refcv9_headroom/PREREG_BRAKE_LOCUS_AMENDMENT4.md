## 1. Arms and populations (as built in `code/brake_locus_reroll_r8.py`)

* **F2** = `set_r8_force(lon6 = CRUISE index 1)` on FB250 (the head intervention incl. allocation; the same arm as force_lon's F2).
* **S0a** = `r8_sel.gamma_prog := 0`; **S0b** = all four `r8_sel` scalars := 0 (eval only; saved, set, restored, restoration asserted by `torch.equal`); EMA-30k learned values `beta_lat -0.0388, beta_lon -0.0068, gamma_prog +0.1010, gamma_head +0.3811` (`BRAKE_LOCUS_ckpt_scalars.json`).  Run on FB250 u CT100.
* **N2** = native at the second sampler draw (offset 7919) on the same windows, the re-draw floor.  Positive controls: **Fbrake** (force BRAKE_TO, LON6 index 2) on CT100; **S0id** (scalars touched and restored, no change) must equal N bit-for-bit; **S0x** (all four scalars x 10) must change the selected candidate on at least one window of the 60-window control subset.
* **FB-N** = the FB250 windows whose RE-ROLLED native plan (arm N, sampler offset 0) has plan class decel (the class rule of the original, section 2, 1.5 m/s).  The F2 / S0 statistics are computed on FB-N only; the number of FB250 windows that already lost the false brake under N is reported (the re-draw flip rate of the banked class).

## 2. Statistic and reading (committed)

For X in {F2, S0a, S0b, N2}: `c_X` = share of FB-N windows on which the arm's plan class is NOT decel (the false brake is gone).  The re-draw floor is `c_N2`.  The N2-adjusted closure `a_X = c_X - c_N2` is paired per window (same windows, shared bootstrap resample), episode-cluster CI.  Windows lacking an arm are dropped from that arm's cell and counted.
Per arm, the force_lon table applied to `a_X`: **CLOSES** iff point(`a_X`) >= 0.50 AND lo(`a_X`) > 0; **NOT-CLOSES** iff hi(`a_X`) < 0.25; else **INCONCLUSIVE** (report the n needed under the 1/sqrt(n) assumption, labelled ESTIMATED).  Gate: the readout is VOID unless (i) S0id equals N on every control window, (ii) S0x moved at least one pick, (iii) Fbrake raises the decel share on CT100 (paired, lo > 0).  A void gate is reported as VOID, not as a result.
Combination (the design's 6.3, mechanical): F2 CLOSES and S0a, S0b NOT-CLOSES -> **HEAD-ACTS-OUTSIDE-RANKING** (allocation or other channels); S0a CLOSES -> **PROGRESS-CONSTRAINT-IS-THE-LOCUS**; S0b CLOSES and S0a does not -> **HEAD-COUPLED-RANKING-TERMS-OTHER-THAN-PROGRESS**; F2, S0a, S0b all NOT-CLOSES -> **PICK-IS-MADE-BY-THE-CORE-RANKING** (the head association is then common-cause); any other pattern -> **MIXED**.  An INCONCLUSIVE arm makes the combination INCONCLUSIVE unless another arm already CLOSES.

Stage order is A (S6 windows, native), BH (hedge arms, AMENDMENT 3), BF (F2 / Fbrake), BS (S0 arms), AL (the remaining ALONG-RAND windows, native + second draw).  The window sets, arms and seeds are those of the design and AMENDMENT 3; only the order differs so that a stop at 2026-10-20 15:00 loses the costliest control (AL, whose expected outcome is stated in advance in A1 A3) first.  The base native forward is SKIPPED in stages without arm N (N is stage A's); verified: arms H1 / S0id / F2 from a no-base roll equal the full-roll arms to 1e-4 m (fp16 fan storage) with the same `sel_idx`.
