# T2-A blockers — what is missing, and exactly what would unblock it

Rule Zero form: each blocker names what unblocks it. A blocked headline does not stop the 0-GPU work (that is all done: see RESULT.md).
Evidence classes: MEASURED (dev box, artifact named) · INHERITED (another document, not re-run) · UNVERIFIED (nobody has run it).

## What is NOT a blocker (checked)

- Checkpoint, both scenes, the P10 weights and the four kit-data files all exist and are in the kit (md5-verified). No licence gate for these two scenes.
- CPU cannot run the model usefully (165-201 s per plan), but nothing requires it to: the GPU run is the only run.
- No data of any kind had to be downloaded, and nothing was sent to Thor or box 2.
